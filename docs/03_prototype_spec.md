## 1. 목적

이 프로토타입은 **게임을 만들기 시작해도 되는지**를 판단하기 위한 것이다. 보기 좋을 필요가 없고, 남길 필요도 없다. 회색 상자로 만든다.

판단할 것은 하나다. **"하나만 더 캐고"와 종소리 사이의 긴장이, 직접 싸우는 3D 탑다운 게임에서 성립하는가.**

### 1.1 여섯 질문과 통과 기준

| # | 질문 | 통과 기준 |
|---|---|---|
| 1 | 절벽을 오르는 적의 **높이가 읽히는가** | 화면을 처음 본 사람이 "가장 먼저 성벽에 닿을 적"을 2초 안에 가리킨다. 5번 중 4번 이상 |
| 2 | 곶에 나가 있을 때 성벽의 **위기가 느껴지는가** | 한 판(30분)에 "종이 울린 뒤에도 더 캐다가 늦게 돌아온" 일이 2회 이상 저절로 일어난다 |
| 3 | 직접 싸우는 방어가 채굴만큼 **재미있는가** | 습격만 10회 연달아 해도 지루하지 않다. 채굴과 방어 중 한쪽이 숙제로 느껴지지 않는다 |
| 4 | 귀환 시간이 **긴장인가, 짜증인가** | 편도 7~14초 구간에서 "걷는 게 지루하다"는 반응이 없다 |
| 5 | 추락 규칙이 **노릴 만한가** | 한 판에 일부러 추락을 노린 행동이 5회 이상 나온다 |
| 6 | 트인 땅에서도 탐사의 **기대가 유지되는가** | 안개 너머로 가 보고 싶어 한다. 채굴이 단순 수거로 느껴지지 않는다 |

테스트는 본인과 외부 사람 3명 이상이 한다. 본인의 판단만으로 통과시키지 않는다.

### 1.2 판정

| 결과 | 다음 행동 |
|---|---|
| 여섯 개 모두 통과 | 5주차부터 본 제작 |
| 1·2·3 중 하나라도 실패 | 본 제작에 들어가지 않는다. 원인을 고치고 최대 1주 더 검증한다. 그래도 안 되면 설계를 바꾼다 |
| 4·5·6 중 실패 | 본 제작에 들어가되, 해당 규칙을 5~9주차 안에 고친다 |

## 2. 범위

### 2.1 넣는 것

| 영역 | 내용 |
|---|---|
| 왕 | 검 형태 하나. 이동, 대시, 기본 3연타, 강공격, 패링, 쓰러짐과 재기 |
| 성 | 성벽 하나(통로 40m), 구역 3개, 시설 슬롯 3칸, 왕좌, 뒷문, 성벽 내구도와 함락 |
| 절벽 | 높이 18m의 계단식 3단. 중앙 절벽면의 등반 레인 6줄, 바위턱 2곳 |
| 적 | 등반병, 방패병, 석궁수, 시험용 대형(절벽 거수의 축소판) |
| 곶 | 땅 하나(옛 채석장). 24×36타일, 세 구간. 타일 4종과 광맥 2종 |
| 채굴과 운반 | 무기로 캐기, 빛의 실, 운반 한도와 속도 감소, 뒷문에서 수령 |
| 주기 | 고요 100초, 경보 15초 전, 습격 10회와 총공세 |
| 강화 | 각성 노드 8개(검 1단계 전부), 왕 강화 2축 × 2단계, 시설 3종, 성벽 수리 |
| 자리 | 봉인실 1곳(성물 둘 중 하나), 낙성지 1곳(대파편 → 총공세) |
| 화면 | 종 게이지, 성벽 내구도, 자원, 운반량, 성벽 띠, 목록형 왕좌 메뉴 |

### 2.2 넣지 않는 것

지팡이와 활, 인장, 룬, 공명, 진명, 보스, 성문길과 좌 절벽면, 컷신과 일러스트, 밀물, 저장과 되감기, 설정 메뉴, 영어, 에셋 적용, 사운드(종소리 하나만 넣는다).

종소리는 넣는다. 질문 2의 답이 종소리에 달려 있기 때문이다.

## 4. 조작, 카메라, 왕

### 4.1 카메라

| 항목 | 값 |
|---|---|
| 투영 | 원근, 시야각 30° |
| 기울기 | 55° (바다 쪽을 향해 내려다본다. 화면 위가 언제나 바다) |
| 거리 | 왕에서 약 28m |
| 추적 | 0.15초 지연으로 왕을 따라간다 |
| 성벽 위에서 | 시점을 벼랑 쪽으로 6m 내린다. 절벽면이 화면 아래 45%를 채운다 |
| 곶에서 | 왕이 화면 중앙. 성벽은 화면 밖이고 '성벽 띠'로만 보인다 |

카메라는 질문 1의 핵심 변수다. 기울기 45°·55°·65° 세 가지를 바꿔 가며 볼 수 있게 만든다.

### 4.2 왕

| 항목 | 값 |
|---|---|
| 이동 속도 | 6 m/s. 가속 0.08초 |
| 대시 | 7m를 0.18초에. 무적 0.15초. 재사용 2초 |
| 체력 | 100. 성벽 위에서 초당 2 회복 |
| 쓰러짐 | 체력 0 → 왕좌에서 6초 뒤 재기. 끌던 자원은 그 자리에 떨어진다 |
| 운반 한도 | 12조각. 6조각을 넘으면 조각당 속도 5% 감소(최대 30%) |

### 4.3 검

| 동작 | 입력 | 값 |
|---|---|---|
| 기본 3연타 | 좌클릭 | 0.30초 / 0.30초 / 0.45초. 피해 12 / 12 / 20. 호 120°, 반경 2.6m. 3타째 밀어냄 4 |
| 강공격 | 좌클릭 누르기 | 충전 0.6초. 피해 35, 반경 3m 원형. 밀어냄 10 |
| 패링 | 우클릭 | 받아치는 창 0.2초. 성공 시 반경 4m 반격파(피해 30, 밀어냄 6). 재사용 1초 |
| 성벽 가장자리 판정 | — | 근접 공격은 성벽 턱에서 **아래로 3m**까지 닿는다. 턱밑까지 올라온 적을 칠 수 있다 |
| 채굴 | 좌클릭 (곶에서) | 타격 한 번이 전방 호 안의 타일 최대 3개에 강도 1씩. 0.3초에 한 번 |

### 4.4 입력

| 행동 | 키보드·마우스 | 게임패드 |
|---|---|---|
| 이동 / 조준 | WASD / 마우스 | 왼쪽 스틱 / 오른쪽 스틱 |
| 기본 공격·채굴 / 패링 | 좌클릭 / 우클릭 | RT / LT |
| 기술 1 / 2 | Q / E | LB / RB |
| 대시 / 상호작용 / 내려놓기 | Space / C / G | A / X / B |

새 Input System으로 만든다. 게임패드는 프로토타입에서도 동작해야 한다.

## 5. 전투

### 5.1 적

| 적 | 체력 | 등반 속도 | 바닥에서 성벽까지 | 붙잡기 | 성벽 피해 | 왕 피해 | 위협 비용 |
|---|---|---|---|---|---|---|---|
| 등반병 | 30 | 0.6 m/s | 30초 | 6 | 초당 2 | 8 | 1 |
| 방패병 | 45 | 0.5 m/s | 36초 | 10 | 초당 3 | 8 | 2 |
| 석궁수 | 25 | 0.6 m/s | 바위턱(12m)까지 20초 | 6 | — | 2.5초마다 10 | 2 |
| 시험용 대형 | 160 | 0.35 m/s | 51초 | 24 | 초당 8 | 20 | 5 |

- **등반병:** 레인을 따라 오른다. 성벽에 오르면 성벽을 공격한다. 왕이 가까우면 왕을 친다.
- **방패병:** 위에서 날아오는 원거리 피해를 70% 줄인다. 근접과 밀어내기에는 그대로 맞는다.
- **석궁수:** 바위턱에 자리 잡고 왕을 쏜다. 성벽 위에서 근접으로는 닿지 않는다. 검기로 잡아야 한다.
- **시험용 대형:** 붙잡기가 강해 한 번에 떨어지지 않는다. 떨어뜨리면 아래의 적을 휩쓴다. 추락 규칙(질문 5)을 시험하기 위한 적이다.

### 5.2 등반

길 찾기를 쓰지 않는다. 적은 자기 레인과 **높이 값 하나**(0~18m)만 가진다. 매 프레임 높이에 등반 속도를 더한다. 18m에 닿으면 성벽 위의 지상 유닛이 된다.

### 5.3 추락

| 규칙 | 값 |
|---|---|
| 붙잡기 | 밀어내는 힘을 받으면 그만큼 깎인다. 1.5초 동안 맞지 않으면 초당 2씩 회복한다 |
| 추락 | 붙잡기가 0 이하가 되면 떨어진다 |
| 낙하 피해 | 떨어진 높이 1m당 8. 18m에서 떨어지면 144 |
| 충돌 | 같은 레인 아래의 적에게 낙하 피해의 50%. 밀어냄은 등반병 4, 대형 12 |
| 살아남으면 | 바닥에서 2초 뒤 다시 오른다 |

밀어내는 힘: 기본 3타째 4, 패링 반격파 6, 강공격 10, 내려찍기 14, 검기(폭발 변형) 6.

등반병은 강공격 한 번에 떨어지고, 대형은 붙잡기가 회복되기 전에 세 번을 쳐야 떨어진다.

### 5.4 성벽

| 항목 | 값 |
|---|---|
| 내구도 | 1,000 |
| 수리 | 흑철 1개로 50. 고요 중 왕좌에서 |
| 함락 | 0이 되면 패배 화면 → 처음부터 다시 |

## 6. 곶

### 6.1 타일

| 타일 | 강도 | 구간 1 | 구간 2 | 구간 3 |
|---|---|---|---|---|
| 흙·자갈 | 4 | 60% | 35% | 20% |
| 연암 | 10 | 25% | 40% | 40% |
| 경암 | 26 | — | 10% | 25% |
| 바위산 (파괴 불가) | — | 10% | 10% | 10% |
| 광맥 | 깔린 암반과 같음 | 5% | 5% | 5% |

- 성광석 광맥 40타일 × 2개 = 80개. 세 구간에 고루, 뒤로 갈수록 조금 더.
- 흑철 광맥 15타일 × 2개 = 30개. 구간 2와 3에만.
- 채굴 위력 Ⅰ(타격당 1) 기준으로 흙 3타일을 1.2초, 연암 3타일을 3초, 경암 3타일을 7.8초에 판다.

### 6.2 해무와 시야

| 구간 | 빛의 반경 |
|---|---|
| 구간 1 | 14m |
| 구간 2 | 11m |
| 구간 3 | 8m |

반경 밖은 안개로 가려진다. 광맥은 반경 안에 들어와야 빛난다. 한 번 본 지형은 지도에 남는다.

### 6.3 자리

| 자리 | 위치 | 내용 |
|---|---|---|
| 봉인실 | 구간 2 | 경암으로 둘러싸인 3×3 방. 성물 둘 중 하나: **길잡이 실타래**(뒷문으로 즉시 귀환, 주기당 1회) / **운반 석상**(떨어진 자원을 뒷문까지 나른다) |
| 낙성지 | 구간 3의 끝 | 대파편. 들어 올리면 "총공세 예고", 성에 닿으면 총공세 시작 |

### 6.4 맞춰야 할 값

밸런스 시트는 1장에서 **채굴 1초당 성광석 0.11개**(고요 한 번에 6~8개)를 가정한다. 프로토타입에서 실제 값을 재고, 다르면 광맥 밀도나 타일 강도를 고친다.

## 7. 주기와 습격

```
  고요 100초 ──(85초 시점: 종)── 습격 (적 전멸까지) ── 고요 100초 ── …
```

- 습격의 적은 시작 후 35초 동안 고르게 나타난다. 레인은 무작위로 나눈다.
- 왕이 곶에 있어도 습격은 시작된다.
- 종소리는 곶 전체에 들린다. 구간 3에서는 작게 들린다.

## 8. 강화

고요 중 왕좌에서 메뉴를 연다. 메뉴가 열려 있는 동안 게임은 멈춘다. 프로토타입에서는 별자리 화면이 아니라 목록으로 만든다.

### 8.1 각성 노드 (검 1단계 전부, 각 성광석 8)

| 가지 | 노드 | 효과 |
|---|---|---|
| 줄기 | 채굴 위력 Ⅰ | 타격당 깎는 강도 1 → 2 |
| 줄기 | 빛의 반경 | 해무 속 시야 +3m |
| 섬광 | **검기** (기술) | 직선 참격. 사거리 18m, 피해 30, 적 3기 관통, 재사용 6초. 곶에서는 직선 5타일에 강도 6 |
| 섬광 | 여세 | 적을 처치하면 2초간 이동 속도 20% 증가 |
| 철벽 | **왕의 방패** (기술) | 패링 창 0.2초 → 0.35초. 반격파 반경 4m → 6m |
| 철벽 | 굳건함 | 패링에 성공하면 성벽 내구도 5 회복 |
| 파멸 | **내려찍기** (기술) | 도약 후 반경 4m 강타. 피해 45, 밀어냄 14, 재사용 8초. 곶에서는 반경 2타일에 강도 8 |
| 파멸 | 무게 | 낙하 피해 30% 증가 |

기술은 두 칸에 장착한다(Q, E). 세 기술 중 둘을 고르게 된다.

### 8.2 왕 강화

| 축 | 1단계 (성광석 12) | 2단계 (성광석 22) |
|---|---|---|
| 다리 | 이동 속도 +10% | +20% |
| 등 | 운반 한도 18 | 24 |

### 8.3 시설 (각 흑철 10, 슬롯 3칸)

| 시설 | 효과 |
|---|---|
| 망루 | 경보가 15초 전에서 20초 전으로. 다음 습격의 편성을 보여 준다 |
| 발리스타 | 4초마다 피해 40. 가장 높이 올라온 적을 먼저 쏜다 |
| 가시 난간 | 맨 위 3m 띠의 적에게 초당 6 피해, 등반 속도 30% 감소 |

### 8.4 살 수 있는 양

1장의 땅에서 표준적으로 성광석 약 70개, 흑철 30개를 캔다. 살 수 있는 것은 노드 8개와 왕 강화 4단계(합계 132) 중 절반 남짓, 시설 3종 중 둘과 약간의 수리다. **전부 살 수 없어야 한다.** 무엇을 먼저 사는지가 테스트의 관찰 대상이다.

## 10. 기술 구조

### 10.1 프로젝트

| 항목 | 내용 |
|---|---|
| 엔진 | Unity 6, 시작 시점의 최신 LTS |
| 렌더 | URP |
| 패키지 | Input System, Cinemachine |
| 저장소 | 이 저장소의 `game/` 폴더에 Unity 프로젝트를 둔다. 유료 에셋 폴더는 `.gitignore`로 제외한다 |

### 10.2 구성

| 모듈 | 책임 |
|---|---|
| `Core` | 게임 상태(고요·경보·습격·총공세·승리·함락), 시간, 이벤트 |
| `King` | 이동, 대시, 체력, 운반 |
| `Combat` | 공격 판정, 피해, 밀어냄, 기술 |
| `Siege` | 레인, 등반, 추락, 습격 스포너, 성벽 내구도, 시설 |
| `Cape` | 타일 격자, 생성, 채굴, 광맥, 해무, 자리 |
| `Progress` | 자원, 노드, 왕 강화, 구매 |
| `UI` | HUD, 성벽 띠, 왕좌 메뉴 |

### 10.3 데이터

수치는 코드에 적지 않는다. 전부 ScriptableObject에 둔다.

| 데이터 | 담는 것 |
|---|---|
| `EnemyDef` | 체력, 등반 속도, 붙잡기, 피해, 위협 비용 |
| `WaveDef` | 습격별 편성 |
| `TileDef` | 강도, 떨어뜨리는 자원 |
| `SkillDef` | 전달 방식, 피해, 범위, 밀어냄, 재사용, 채굴 효과 |
| `NodeDef` | 비용, 효과 |
| `FacilityDef` | 비용, 효과 수치 |
| `Tuning` | 이동 속도, 고요 길이, 운반 한도 등 전역 값 |

플레이 중에 값을 바꿔 가며 볼 수 있어야 한다. 프로토타입의 일은 숫자를 찾는 것이다.

## 11. 작업 순서

각 항목은 Claude에게 하나씩 맡길 수 있는 크기로 나눴다. 완료 기준을 만족해야 다음으로 넘어간다.

### 1주차 — 성벽에서 싸운다

| # | 작업 | 완료 기준 |
|---|---|---|
| 1 | 프로젝트 생성, URP, Input System, Cinemachine, 폴더와 모듈 | 빈 장면이 실행된다 |
| 2 | 왕의 이동·조준·대시 (키보드와 패드) | 성벽 통로를 6.7초에 가로지른다 |
| 3 | 성벽·절벽·안뜰의 회색 상자, 카메라 | 절벽 3단이 화면에서 구분된다. 기울기를 바꿀 수 있다 |
| 4 | 레인과 등반병의 등반 | 등반병 10기가 30초에 걸쳐 올라와 성벽에 선다 |
| 5 | 기본 3연타, 강공격, 피해, 체력 | 턱밑 3m의 적과 성벽 위의 적이 맞는다 |
| 6 | 붙잡기와 추락, 낙하 피해, 충돌 | 강공격으로 등반병이 떨어지고 아래의 적이 휩쓸린다 |
| 7 | 성벽 내구도, 적의 성벽 공격, 함락 | 방치하면 함락 화면이 뜬다 |

| # | 작업 | 완료 기준 |
|---|---|---|
