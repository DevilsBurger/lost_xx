## 1. 게임 개요

### 1.1 한 줄 소개

**성 뒤편 곶을 파 나아가 부서진 무기를 깨우고, 종이 울리면 성벽으로 돌아와 절벽을 기어오르는 군세를 직접 베어 떨어뜨리는 3D 탑다운 채굴·방어 액션.**

### 1.2 기본 정보

| 항목 | 내용 |
|---|---|
| 제목 | **LOST REGALIA** (확정. 상표·스팀 중복 확인은 남은 일) |
| 장르 | 채굴 × 거점 방어 × 액션 |
| 모드 | **캠페인** — 이야기가 있고 모든 성장이 영구히 쌓인다 / **농성** — 빈 성에서 시작하는 한 판짜리 |
| 시점 | 3D 탑다운, 고정 고각 카메라 |
| 플랫폼 | PC (Steam), Steam Deck 대응 |
| 인원 | **1인 플레이 전용** (확정). 협동은 넣지 않는다 |
| 벤치마크 | Dome Keeper — 핵심 루프와 가격대 |
| 플레이타임 | 캠페인 첫 클리어 6~8시간 (장당 약 50분 × 5장 + 재도전). 농성 한 판 40~60분. 형태 3종과 농성을 합치면 수십 시간 |
| 가격 | 돔 키퍼 정가($17.99)와 같은 수준. 지역 가격은 스팀 권장가를 따른다 |
| 타깃 | 돔 키퍼류의 '채굴과 방어 사이의 긴장'을 좋아하고, 빌드 연구에 시간을 쓰는 플레이어 |
| 언어 | 한국어·영어 (출시), 일본어·중국어 간체 (검토) |
| 엔진 | Unity 6 |
| 제작 | 1인. **기간에 제한을 두지 않는다. 재미가 기준이다.** Claude(코드·데이터·글), Midjourney(2D 일러스트·아이콘), Unity 에셋 스토어(3D 모델·애니메이션·VFX·사운드) |

### 1.3 설계 기둥

모든 기능은 아래 다섯 문장 중 하나 이상에 기여해야 한다. 그렇지 않으면 뺀다. 기간에 제한이 없다는 것은 무엇이든 넣는다는 뜻이 아니다.

| # | 기둥 | 뜻 |
|---|---|---|
| 1 | **탐욕과 귀환** | "하나만 더 캐고"와 종소리 사이의 줄다리기가 게임의 심장이다. |
| 2 | **왕이 직접 싸운다** | 포탑을 조작하는 것이 아니라, 플레이어의 손이 곧 방어선이다. |
| 3 | **깨어나는 무기** | 무기는 하나다. 그러나 깨우는 순서와 조합에 따라 전혀 다른 무기가 된다. |
| 4 | **쌓은 것은 남는다** | 무기도, 성도, 왕도, 판 길도 캠페인 내내 남는다. 대신 자원에는 끝이 있고, 적은 장마다 새 길을 뚫는다. |
| 5 | **한 판 더** | 캠페인이 끝나도 게임은 끝나지 않는다. 다른 형태, 다른 빌드, 농성 한 판, 스스로 거는 서약. |

### 1.4 재미의 순간

이 게임이 재미있어야 하는 순간을 여섯 개로 정한다. 시스템은 이 순간들을 더 자주, 더 선명하게 만들기 위해 있다.

| 순간 | 만드는 시스템 |
|---|---|
| 종이 울리는데 광맥이 눈앞에 있다 | 고요와 습격의 주기, 운반 한도, 귀환 거리, 해무 |
| 늦게 돌아와 성벽 위의 적을 한 번에 쓸어 낸다 | **왕의 귀환**([6.2](#62-왕의-상태)), 범위 기술 |
| 턱밑까지 올라온 한 줄을 떨어뜨려 아래까지 휩쓴다 | 추락([12.3](#123-추락--이-게임만의-전투-규칙)) |
| 새로 깨운 노드 하나가 빌드 전체를 바꾼다 | 변형 분기, 인장과 반응, 룬, 진명 |
| 어제는 모자랐던 성이 오늘은 버틴다 | 영구 누적, 시설과 특화 |
| 지금까지 쌓은 것이 새 적 앞에서 모자라다 | 장마다 늘어나는 경로와 적, 장의 사건 |

### 1.5 차별점

- **절벽이라는 전장.** 적은 걸어오지 않고 기어오른다. 높이 올라온 적일수록 떨어뜨렸을 때 이득이 크다.
- **앞은 벼랑, 뒤는 바다.** 성벽과 채굴지가 한 장의 지도로 이어진다. 캘 수 있는 땅에는 끝이 있고, 그 끝이 캠페인의 끝이다.
- **무기 하나로 캐고 싸운다.** 채굴 도구와 전투 무기가 같다. 전투 빌드가 곧 채굴 빌드다.
- **여섯 겹의 조합.** 형태 → 기술 → 변형 → 인장 → 룬 → 진명·공명·부형태. 층마다 선택이 다음 층의 선택지를 바꾼다.
- **두 가지 호흡.** 하나의 성을 끝까지 키우는 캠페인과, 빈손에서 요새까지를 한 판에 담는 농성.
- **짧고 완결된 이야기.** 기억 하나가 스킬 트리의 한 단계를 연다. 이야기 보상과 성장 보상이 같은 순간에 온다.

## 2. 벤치마크 — 돔 키퍼에서 가져오는 것과 바꾸는 것

### 2.1 구조

돔 키퍼의 재미는 **"안전하지만 가난한 지상"과 "풍요롭지만 먼 지하" 사이를 오가는 시간 관리**에 있다. 이 구조는 그대로 가져오되, 위아래를 앞뒤로 눕힌다. 지하 대신 성 뒤편의 땅을 캔다. 그 밖에 바꾸는 것은 방어의 방식과 성장의 깊이다.

| 돔 키퍼 | 본작 | 바꾸는 이유 |
|---|---|---|
| 돔 (방어 거점) | 절벽성의 성벽 | 설정. 패배 조건은 동일하게 '거점 내구도 0' |
| 돔 아래 지하를 채굴 (2D 횡스크롤) | 성 뒤편 '곶'을 채굴 (3D 탑다운 타일) | 성벽과 채굴지가 한 장의 지도로 이어진다. 시점·조작 통일 |
| 깊이 내려갈수록 풍요롭고 멀다 | 바다에 가까울수록 풍요롭고 멀다. 땅끝이 한계 | 세계에 끝을 둔다. 땅의 끝이 캠페인의 끝 |
| 돔에 달린 무기를 조작 | 왕이 레갈리아를 들고 직접 전투 | 액션의 손맛, 빌드가 화면에 드러남 |
| 굴착기와 돔 무기가 별개 | 레갈리아 하나로 채굴과 전투 | 강화 선택의 무게를 키움 |
| 자원 3종 (철·물·코발트) | 성광석·흑철·룬 수정 (+ 적이 떨어뜨리는 마정) | 용도를 각성·성·조합으로 분리 |
| 가젯 (택1) | 성물 (택1) + 룬 | 조합 층 추가 |
| 유물을 지상으로 가져오면 승리 | 대파편을 가져오면 총공세 → 보스 → 장 클리어 | 플레이어가 클라이맥스 시점을 정하는 구조 유지 |
| 매 판 처음부터 다시 (로그라이크) | **두 모드로 나눈다.** 캠페인은 초기화 없이 영구 누적, 농성은 매 판 처음부터 | 성 하나를 끝까지 키우는 애착과, 한 판의 완결된 곡선을 둘 다 갖는다 |
| 키퍼는 죽지 않는다 | 왕은 쓰러지지만 죽지 않는다 | 패배 조건을 '성' 하나로 유지 |
| 채굴지에는 적이 없다 | 동일. 성벽이 버티는 한 곶은 안전하다 | "곶은 탐욕, 성벽은 공포"의 리듬 보존 |

**버리는 것:** 채굴지 전투, 다수 유닛 지휘, 건설 배치 퍼즐. 초점을 흐린다.

### 2.2 규모

| | 돔 키퍼 | 본작 |
|---|---|---|
| 팀 | 2인 개발사 + 외부 작곡가, 퍼블리셔 있음 | 1인 + AI 도구 + 에셋 팩 |
| 기간 | 게임잼(2021년 4월)에서 출시(2022년 9월)까지 약 17개월 | 제한 없음 |
| 가격 | $17.99 | 같은 수준 |
| 플레이타임 | 메인 4.5~6시간, 부가 요소 포함 약 13시간 | 캠페인 6~8시간, 농성과 형태 3종으로 수십 시간 |

가격대는 돔 키퍼에 맞춘다. 콘텐츠와 플레이타임은 돔 키퍼를 기준선으로 삼되 넘어서는 것을 목표로 한다. 돔 키퍼는 출시 당시 "가격에 비해 콘텐츠가 적다"는 평을 받았다. 같은 가격에 더 깊은 조합과 두 가지 모드를 내는 것이 본작의 값이다.

## 3. 핵심 루프

### 3.1 한 주기 (약 2~3분)

```
        ┌───────────────  고요  ───────────────┐
        │   ① 나간다 → ② 캔다 → ③ 나른다        │
        │  바다에 가까울수록 많이 얻고, 멀어진다  │
        └──────────────────┬──────────────────┘
                           │  종이 울린다 (경보)
                           ▼
        ┌───────────────  습격  ───────────────┐
        │   ④ 돌아온다 → ⑤ 성벽에서 싸운다       │
        └──────────────────┬──────────────────┘
                           ▼
              ⑥ 깨운다 · 짓는다 · 고친다
           (레갈리아 각성 / 방어 시설 / 성벽 수리)
                           │
                           └────► 다시 ①
```

### 3.2 세 가지 시간 단위

| 단위 | 길이 | 내용 | 플레이어의 질문 |
|---|---|---|---|
| **주기** | 2~3분 | 고요 → 습격 → 강화 | "지금 돌아갈까, 하나만 더 캘까?" |
| **장** | 약 50분 | 주기 12회 → 대파편 회수 → 총공세 → 보스 | "무기에 쓸까, 성에 쓸까? 대파편은 언제 가져갈까?" |
| **캠페인** | 6~8시간 | 5장. 무기도 성도 왕도 쌓인다. 적이 오는 길도 쌓인다 | "끝이 있는 자원으로 무엇을 끝까지 키울 것인가?" |

### 3.3 한 장의 흐름 (1장 예시)

| 시점 | 벌어지는 일 |
|---|---|
| 0분 | 반쯤 무너진 성. 시설 없음. 뒷문으로 나가 첫 땅으로 향한다. |
| 0~12분 | 첫 구간. 성에서 가깝다. 흙과 연암을 파며 성광석을 모은다. 습격은 약하다. 첫 시설(망루 또는 발리스타)을 짓는다. |
| 12~28분 | 둘째 구간. 흑철이 나오기 시작하고 귀환이 길어진다. 봉인실에서 성물을 고른다. 습격에 석궁수와 방패병이 섞인다. |
| 28~42분 | 마지막 구간. 낙성지를 찾는다. **대파편을 성으로 가져갈지 결정한다.** 성에 닿는 순간 총공세가 시작된다. 준비가 덜 됐다면 더 캔다. 그러나 습격은 계속 강해진다. |
| 42~50분 | 총공세와 보스. 승리하면 성은 상처 하나를 얻고(성문이 부서진다), 다음 땅이 열린다. |

2장부터는 지은 것이 모두 남아 있다. 장의 과제는 다시 짓기가 아니라, 새 땅과 새 적과 새 경로에 맞춰 **더 짓고 고쳐 짓는 것**이다.

## 4. 세계와 이야기

전문은 [시나리오 문서](./01_scenario.md)에 있다. 기획에 필요한 요점만 옮긴다.

- **상황:** 절벽성 그레이홀트. 왕이 기억을 잃고 깨어난다. 손에는 형태 없는 왕가의 증표 '레갈리아'. 절벽 아래에는 마계와 손잡은 옛 적수 발카르의 군세.
- **레갈리아가 약한 이유:** 발카르의 저주를 대신 맞고 부서졌다. 힘과 기억은 파편이 되어 성 뒤편 곶에 흩어져 떨어졌다. 큰 조각일수록 멀리, 바다 쪽으로. → **곶 탐사의 이유.**
- **기억 다섯 개:** 장마다 대파편 하나를 되찾고, 그때마다 기억과 각성 단계가 함께 열린다. → **성장의 박자.**
- **진실:** 10년 전 왕은 발카르를 '살려 보낸' 것이 아니라 "벨 가치도 없다"며 버려두었다. 침공은 그 한마디의 값이다.
- **성의 상처:** 왕이 지은 것은 남는다. 그러나 장이 끝날 때마다 성은 상처를 하나 얻는다(성문, 서쪽 벼랑, 균열, 종탑). → **적이 오는 길이 하나씩 영구히 늘어난다.**
- **앞은 벼랑, 뒤는 바다:** 곶의 끝은 바다다. 장마다 한 땅씩 나아가 5장에서 땅끝에 닿는다. → **세계의 한계, 캠페인의 길이.**
- **결말 둘:** 벤다(계약 완결, 마계는 다시 온다) / 손을 내민다(계약을 태우고 레갈리아를 잃는다 — 진결말).

## 5. 게임 공간 — 성벽과 곶

### 5.1 전체 구조

세계는 **한 장으로 이어진 지도**다. 앞에는 벼랑, 가운데에 성, 뒤에는 바다로 끝나는 곶이 있다. 적은 앞에서 오고, 자원은 뒤에 있다. 왕은 그 사이를 오간다.

```
 [전체 지도 — 탑다운. 아래가 벼랑, 위가 바다]

   ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈  바다 (세계의 끝)  ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈
   ≈ ┌───────────────────────────────────┐ ≈
   ≈ │ 5. 땅끝 · 첫 모루              ◆  │ ≈
   ≈ ├───────────────────────────────────┤ ≈   바다에 가까울수록
   ≈ │ 4. 해무의 황야                 ◆  │ ≈   자원↑  암반 강도↑
   ≈ ├───────────────────────────────────┤ ≈   해무↑  귀환 시간↑
   ≈ │ 3. 별 떨어진 분지              ◆  │ ≈
   ≈ ├───────────────────────────────────┤ ≈   ◆ 대파편이 떨어진 곳
   ≈ │ 2. 왕릉 언덕                   ◆  │ ≈     (낙성지)
   ≈ ├───────────────────────────────────┤ ≈
   ≈ │ 1. 옛 채석장                   ◆  │ ≈
   ≈ └──────────────┬─ 뒷문 ─┬───────────┘ ≈
     ┌──────────────┴────────┴───────────┐
     │      성  (왕좌 · 안뜰 · 종탑)       │
     ╞═══════════ 성벽 (전투) ════════════╡
        ▲ ▲ ▲    절벽면    ▲ ▲ ▲    ▲ 성문길
     ~~~~~~~ 벼랑 아래: 적 진영 · 균열 ~~~~~~~
```

| 원칙 | 내용 |
|---|---|
| **끝이 있다** | 곶은 좌우와 뒤가 모두 바다다. 캘 수 있는 땅은 정해져 있다. |
| **장마다 한 땅** | 곶은 다섯 땅으로 나뉜다. 장마다 바다 쪽으로 한 땅이 더 열린다. 5장의 땅끝이 마지막이다. |
| **판 자리는 남는다** | 지나온 땅의 지형과 길은 캠페인 내내 유지된다. |
| **곶은 안전하다** | 적은 벼랑에서만 온다. 성벽이 버티는 한 곶에는 전투가 없다. |

캠페인이 진행되면 **적은 벼랑 쪽에서 새 길을 하나씩 뚫고, 왕은 바다 쪽으로 한 땅씩 나아간다.** 5장에서 왕은 땅끝에 닿는다. 더 캘 땅은 없다. 그때까지 쌓은 것으로 버텨야 한다.

### 5.2 성벽

카메라는 **벼랑 바깥 허공에서 성을 바라보는 고각**(약 55°)이다. 화면 위쪽이 성 안, 가운데가 성벽 위 통로, 아래쪽이 절벽면이다. 적은 화면 아래에서 위로 올라온다. 카메라의 방향은 곶에서도 같다. 화면 위쪽이 언제나 바다다. 아래 그림은 모든 경로가 열린 5장 기준이다.

```
 ┌────────────────────── 화면 ──────────────────────┐
 │                  ↑ 뒷문 · 곶 · 바다                │
 │   왕좌(재기)        안뜰            종탑           │ ← 성 안쪽
 │ ═══╦═══════════╦═══════════╦═══════════╦═══════ │
 │    ║  구역 1   ║   구역 2   ║   구역 3   ║ 성문탑 │ ← 성벽 위 통로 (왕의 전장)
 │ ═══╩═══════════╩═══════════╩═══════════╩═══╗    │
 │   ▲ ▲ ▲         ▲ ▲ ▲ ▲         ▲ ▲        ║ ▲  │ ← 절벽면 (계단식 암반)
 │   좌 절벽면      중앙 절벽면      바위턱      ║성문길│
 │   ▲   ▲           ▲   ▲                    ║ ▲  │
 │ ~~~~~~~~~~ 벼랑 아래: 적 진영 · 균열 ~~~~~~~~~~~~ │
 └──────────────────────────────────────────────────┘
```

| 요소 | 규칙 |
|---|---|
| 성벽 위 통로 | 좌우로 긴 띠. 끝에서 끝까지 달려 약 7초. 양쪽이 동시에 뚫리면 한쪽을 포기해야 한다. |
| 구역 | 구역마다 시설 슬롯이 있다. 성은 반쯤 무너진 채 시작하고, 장마다 구역이 복구되어 슬롯이 3칸에서 8칸으로 늘어난다. |
| 성벽 내구도 | 성 전체에 하나. 0이 되면 함락(패배). |
| 접근 경로 | ① 중앙 절벽면 ② 성문길(중장갑·공성) ③ 좌 절벽면 ④ 공중. 처음에는 ①뿐이고 장마다 열린다 ([13.1](#131-같은-성-달라지는-전장)) |
| 절벽면 | 계단식 암반 3단(높이 18m). 적의 높이가 한눈에 읽혀야 한다. 바위턱은 원거리 적이 자리 잡는 곳이다. |
| 적이 성벽에 닿으면 | 성벽 내구도와 시설을 공격한다. 일부는 왕을 노린다. |

### 5.3 곶

- 탑다운 타일 채굴. 상세는 [11장](#11-곶-탐사).
- **해무:** 바다에서 안개가 밀려온다. 바다에 가까울수록 짙다. 레갈리아의 빛이 닿는 반경이 곧 시야다.
- **종소리:** 종은 곶 전체에 울린다. 멀리 나갈수록 작게 들린다.
- **성벽 감시:** 곶에 나가 있는 동안 화면 위에 '성벽 띠'(성벽 축소도)가 뜬다. 공격받는 구역이 붉게 깜박인다.
- 카메라는 왕을 따라간다. 곶에 나가면 성벽은 화면 밖이다.

### 5.4 뒷문과 귀환

뒷문은 성과 곶을 잇는 유일한 통로다. **귀환 시간이 긴장의 원천**이므로 순간이동은 기본으로 주지 않는다. 깊이 대신 **성에서의 거리**가 위험이다.

| 이동 | 시간 |
|---|---|
| 성벽 ↔ 뒷문 ↔ 첫 땅 어귀 | 약 5초 |
| 지나온 땅 하나 (닦인 길) | +4초 |
| 현재 땅의 구간 하나 | +4초 |
| 광차 선로 시설 | 선로가 깔린 곳의 이동 시간 절반, 운반 한도 2배 |

- **닦인 길:** 장을 끝낸 땅에는 길이 난다. 지나온 땅은 빠르게 통과한다. 그래서 후반에도 귀환 시간을 좌우하는 것은 '지금 캐는 땅에서 얼마나 멀리 나갔는가'다.

## 7. 레갈리아 — 세 가지 형태

프롤로그에서 하나를 고른다. 캠페인 중에는 바꿀 수 없다. 세 형태는 **적을 어느 높이에서 처리하는가**로 갈린다.

| | 검 | 지팡이 | 활 |
|---|---|---|---|
| 교전 높이 | 성벽 가장자리 (근거리) | 절벽면 전체 (중거리) | 절벽 아래~중턱 (원거리) |
| 성벽에서의 방식 | 올라온 적을 베고, 패링하고, 밀어 떨어뜨린다 | 지대·설치·소환으로 절벽을 요새화한다 | 올라오기 전에 솎아 낸다. 약점과 관통 |
| 강점 | 순간 화력, 추락 유발 | 넓은 범위, 왕이 자리를 비워도 버팀 | 안전거리, 후방의 위험한 적 제거 |
| 약점 | 왕이 늘 위험하다. 바위턱·공중·후방의 적에 약함 | 느리다. 준비가 필요하다 | 성벽에 붙은 적에게 약함 |
| 고유 동작 | **패링** — 맞는 순간 받아치면 반격 | **룬 설치** — 기술을 그 자리에 심는다 | **집중** — 느려지는 대신 약점이 보인다 |
| 채굴 특성 | 전방 3타일을 넓게, 빠르게 | 충전 후 원격 범위 폭파 | 직선으로 멀리 관통. 먼 광맥을 쏘아 떨어뜨림 |
| 곶에서의 방식 | 넓은 길을 빠르게 낸다 | 한 번에 크게 무너뜨린다 | 좁고 긴 길로 멀리 찌른다 |
| 권장 숙련도 | 중 | 상 | 하~중 |
| 왕의 모습 | 선두에 서는 왕 | 다스리는 왕 | 내다보는 왕 |

**공통 기본기:** 기본 공격 / 강공격(충전) / 고유 동작 / 대시.

## 8. 각성 시스템 — 스킬 트리와 조합

이 게임의 장기 재미를 책임지는 장이다.

### 8.1 설계 목표

1. **한 무기, 여러 플레이.** 같은 검이라도 빌드에 따라 손의 움직임이 달라져야 한다.
2. **선택에는 대가.** 한 캠페인에서 트리의 약 55%만 깨울 수 있다. 전부 가질 수 없다.
3. **실험은 공짜.** 고요 중 왕좌에서 무료로 재배치한다. 고민은 시키되 벌은 주지 않는다.
4. **층층이 쌓이는 조합.** 한 층의 선택이 다음 층의 가치를 바꾼다.
5. **빌드가 시간 배분을 바꾼다.** 직접 싸우는 빌드는 성벽에 묶이고, 설치·소환 빌드는 곶에 오래 머문다. 빌드 선택이 곧 '탐욕과 귀환'의 답이다.
6. **장마다 새 장난감.** 장이 바뀔 때마다 새 기술, 새 층, 새 규칙이 하나씩 열린다. 궁극기를 끝에 가서야 주지 않는다.

### 8.2 조합의 여섯 층

| 층 | 무엇을 고르나 | 선택 폭 | 얻는 곳 |
|---|---|---|---|
| ① **형태** | 검 / 지팡이 / 활 | 3 중 1 | 프롤로그 |
| ② **기술** | 능동 기술 9개 중 3개 장착 + 궁극기 3개 중 1개 | 가지 3개에 3개씩 | 각성 트리 |
| ③ **변형** | 기술마다 2단 분기(A/B) → 기술 하나당 최종형 4종 | 기술 9 × 4형 | 각성 트리 |
| ④ **인장** | 기술 슬롯마다 속성 하나 (5종) | 슬롯당 5 중 1 | 대파편·보스 |
| ⑤ **룬** | 기술 소켓 1~3칸에 끼워 동작을 바꿈 (20종) | 소켓당 1 | 곶의 봉인실 |
| ⑥ **진명·공명·부형태** | 규칙을 바꾸는 진명(최대 3), 태그 공명, 다른 형태의 가지 하나 | — | 트리·수집·3장 클리어 |

### 8.3 각성 트리의 구조

화면 은유는 **레갈리아 안에 잠든 별자리**다. 노드는 별, 가지는 성좌. 깨울 때마다 별이 켜진다.

```
 단계      〈가지 A〉            〈가지 B〉            〈가지 C〉

 5        ◇ [진화] ●          ◇ [진화] ●          ◇ [진화] ●
 4        ◇ [궁극] ◇ ● ●──✦──◇ [궁극] ◇ ● ●──✦──◇ [궁극] ◇ ● ●
 3        ◆ [진명] ◇ ◇ ●      ◆ [진명] ◇ ◇ ●      ◆ [진명] ◇ ◇ ●
 2        ◆ ◇ ● ●─────✦──────◆ ◇ ● ●─────✦──────◆ ◇ ● ●
 1        ◆ ●                 ◆ ●                 ◆ ●
              ╲                    │                    ╱
               ╲─────────── [ 줄기 6 ] ───────────────╱

 ◆ 능동 기술   ◇ 변형 분기 (A/B 중 하나)   ● 수동   ✦ 교차 노드 (양쪽 가지에 투자해야 열림)
```

**형태당 노드 69개 (세 형태 합계 207개)**

| 구분 | 수 | 내용 |
|---|---|---|
| 줄기 | 6 | 채굴 위력 Ⅰ·Ⅱ·Ⅲ, 빛의 반경, 기본기 숙련, 레갈리아의 맥동 |
| 가지 3개 × 19 | 57 | 가지 하나 = 기술 3 + 변형 분기 6 + 수동 7 + 진명 1 + 궁극 1 + 궁극 진화 1 |
| 교차 노드 | 6 | 인접한 두 가지에 각 5노드 이상 투자하면 열리는 혼합 효과 |

**노드의 종류**

| 종류 | 역할 |
|---|---|
| 기술 | 새 능동 기술을 연다. 장착 칸은 3개뿐이다. |
| 변형 분기 | A와 B 중 하나만 고른다. 기술의 동작이 달라진다. |
| 수동 | 조건부 효과 중심. 단순 수치 증가는 전체의 30% 이하로 묶는다. |
| 교차 | 두 가지의 성격을 섞는다. 혼합 빌드의 보상. |
| **진명** | 규칙을 바꾼다. 큰 이득과 뚜렷한 대가가 함께 온다. |
| 궁극 | 가지의 완성형 기술. 하나만 장착한다. |
| 궁극 진화 | 궁극기가 그 가지의 진명 효과를 함께 받고, 범위와 지속이 커진다. |

**단계의 개방 — 장마다 새 장난감**

| 시점 | 열리는 것 |
|---|---|
| 프롤로그 | 1단계 — 가지의 첫 기술 |
| 1장 대파편 | 2단계 — 가지의 둘째 기술, 첫 변형 · 인장 택1 (화염/서리/뇌전) · 룬 소켓 |
| 2장 대파편 | 3단계 — **진명**, 가지의 셋째 기술 · 진명 슬롯 1 · 인장 택1 |
| 3장 대파편 | 4단계 — **궁극기** · 성광 인장 |
| 3장 클리어 | 공허 인장 제안 · **부형태** |
| 4장 대파편 | 5단계 — 궁극 진화 · 진명 슬롯 2 · 남은 인장 |
| 5장 대파편 | **진명 해방** — 진명 슬롯 3 |

- 대파편은 **회수한 순간** 효력이 생긴다. 새 단계의 힘을 그 장의 보스전에서 바로 쓴다.
- 궁극기는 캠페인의 중간(3장 보스전)에 온다. 4장과 5장 내내 쓸 수 있다.
- 교차 노드는 단계와 무관하게 양쪽 가지의 투자량만으로 열린다.

### 8.4 형태별 가지와 기술

모든 능동 기술은 **곶에서 채굴 효과**를 겸한다. (예: 검기는 직선 5타일을 판다.)

#### 검

| 가지 | 성격 | 기술 | 진명 | 궁극 |
|---|---|---|---|---|
| **섬광** | 속도·연격·검기 | 검기(절벽 아래로 날아가는 참격) · 질풍베기(돌진 베기) · 잔상(분신이 직전 공격을 반복) | **멈추지 않는 칼** — 연속 처치마다 공격 속도 누적. 3초간 처치가 없으면 전부 사라지고 잠시 둔화 | **무영** — 3초 동안 성벽 위의 모든 적을 차례로 벤다 |
| **철벽** | 패링·반격·수호 | 왕의 방패(방패 자세로 막고, 맞는 순간 받아치면 반격파) · 도발의 함성(적이 성벽 대신 왕을 노림) · 불퇴(짧은 시간 밀려나지 않고 받은 피해를 되돌림) | **한 걸음도** — 성벽이 받는 피해의 40%를 왕이 대신 받는다. 왕의 체력 재생 대폭 증가 | **부동** — 5초 동안 성벽이 피해를 받지 않고, 막아 낸 피해를 충격파로 되돌린다 |
| **파멸** | 충전·범위·추락 | 내려찍기(범위 강타, 등반 중인 적을 떨어뜨림) · 대지 가르기(절벽면을 타고 내려가는 균열) · 처형(약해진 적 즉사, 처치 시 재사용) | **성을 부수는 검** — 모든 공격이 충전 공격이 된다. 피해·범위 대폭 증가, 연타 불가 | **벼랑 가르기** — 성벽 가장자리 전체에 충격파. 등반 중인 모든 적의 붙잡기를 크게 깎는다 |

| **난사** | 다중·속사·도탄 | 부채살(부채꼴 다중 사격) · 화살비(지대) · 도탄(적 사이를 튕김) | **빈 화살통** — 조준이 자동이 된다. 공격 속도 2배, 치명타 없음 | **천 개의 화살** — 10초 동안 장전 없이 쏜다 |

#### 변형 분기의 예 — 검기

| 분기 | A | B |
|---|---|---|
| 1차 (2단계) | **관통** — 약하지만 절벽 아래까지 닿는다 | **폭발** — 가까이서 터지며 밀어낸다 |
| 2차 (3단계) | **삼연** — 세 갈래로 나간다 | **회귀** — 되돌아오며 한 번 더 벤다 |

같은 검기가 '관통·삼연'이면 원거리 견제기, '폭발·회귀'면 성벽 가장자리의 추락 유발기가 된다.

#### 교차 노드의 예 — 검

| 가지 쌍 | 노드 | 효과 |
|---|---|---|
| 섬광 × 철벽 | 받아치고 벤다 | 패링에 성공하면 질풍베기의 재사용 대기가 사라진다 |
| 철벽 × 파멸 | 버티고 부순다 | 도발당한 적은 붙잡기가 절반이 된다 |
| 파멸 × 섬광 | 떨어지는 칼 | 추락시킨 적의 수만큼 다음 검기가 강해진다 |

**제작 원칙:** 기술을 따로따로 만들지 않는다. 전달 방식 일곱 가지(호 베기, 직선 투사체, 낙하, 지대, 설치물, 소환수, 자기 중심 파동)의 조합으로 데이터에서 조립한다. 인장과 룬은 전달 방식에 걸리므로 모든 기술에 자동으로 적용된다.

### 8.5 인장 — 속성과 반응

기술 슬롯마다 인장 하나를 찍는다. 인장은 그 기술의 피해 속성과 상태이상을 정한다.

| 인장 | 상태이상 | 효과 | 잘 맞는 상황 |
|---|---|---|---|
| **화염** | 점화 | 지속 피해. 처치 시 인접 적에게 번진다 | 오래 기어오르는 무리 |
| **서리** | 냉기 → 빙결 | 둔화 누적, 5중첩 시 2초 정지. 등반 중 빙결되면 떨어뜨리기 쉽다 | 추락 빌드, 시간 벌기 |
| **뇌전** | 감전 | 피해 일부가 가까운 적 둘에게 연쇄 | 밀집한 무리 |
| **성광** | 낙인 | 마계 적에게 추가 피해. 낙인 대상 처치 시 성벽 소량 회복 | 장기전, 수호 빌드 |
| **공허** | 침식 | 적 최대 체력 비례 피해. **쓸 때마다 부채가 쌓인다** | 보스·대형 적 |

**반응** — 서로 다른 두 상태이상이 한 적에게 겹치면 발동한다.

| | 서리 | 뇌전 | 성광 | 공허 |
|---|---|---|---|---|
| **화염** | **파열** — 빙결을 터뜨려 방어 감소와 범위 피해 | **폭뢰** — 범위 폭발, 밀어냄 | **정화의 불** — 점화가 번질 때 낙인도 함께 번진다 | **재** — 처치한 적이 다시 일어나지 못한다 |
| **서리** | — | **전도** — 빙결된 적을 지나는 연쇄는 약해지지 않는다 | **빙벽** — 빙결된 적이 잠시 벽이 되어 뒤따르는 등반을 막는다 | **정적** — 범위 안의 적 능력 봉쇄 |
| **뇌전** | | — | **천벌** — 낙인 대상에게 낙뢰 추가타 | **누전** — 연쇄가 침식을 함께 옮긴다 |
| **성광** | | | — | **일식** — 큰 단일 피해, 부채 일부 탕감 |

**부채** — 발카르와 같은 길

공허 인장은 3장에서 징수인을 물리친 뒤, 그가 물러가며 남기는 '제안'으로 온다. **받을지 말지는 플레이어가 정한다.**

| 부채 게이지 | 결과 |
|---|---|
| 33% | 다음 습격에 엘리트 '징수꾼'이 섞인다 |
| 66% | 성벽 최대 내구도 감소 |
| 100% | **징수** — 성벽에 즉시 큰 피해. 게이지는 0으로 돌아간다 |

- 상환 수단: '일식' 반응, 왕좌에서 성광석 봉헌, 징수꾼 처치.
- 의도: 가장 강한 힘에 이자를 붙인다. 플레이어가 발카르의 선택을 직접 저울질하게 한다.

### 8.6 룬 — 기술의 동작을 바꾼다

곶의 봉인실과 보스에게서 얻는다. 기술 소켓에 끼운다. 소켓은 기술당 1칸에서 시작하고, 룬 수정으로 3칸까지 연다. 출시 시점 20종.

| 룬 | 효과 | 태그 |
|---|---|---|
| 분열 | 투사체·충격파가 둘로 갈라진다 | 연쇄 |
| 반향 | 일정 확률로 한 번 더 발동 | 연쇄 |
| 관통 | 적을 뚫고 지나간다 | — |
| 잔류 | 기술이 지나간 자리에 지대를 남긴다 | 지대 |
| 확산 | 범위가 늘고 피해가 준다 | 지대 |
| 응축 | 범위가 줄고 피해가 는다 | 처형 |
| **설치** | 기술을 성벽에 거치한다. 주기적으로 자동 발동, 위력은 줄어든다 | 설치 |
| 지연 | 늦게 터지고 더 세게 터진다 | — |
| 밀침 | 밀어내는 힘 증가 | 추락 |
| 표적 | 맞은 적에게 표식을 남긴다 | 표식 |
| 흡수 | 처치 시 왕 또는 성벽 소량 회복 | 수호 |
| 굴착 | 곶에서 이 기술의 채굴 범위·위력 증가 | — |

**'설치' 룬은 빌드의 갈림길이다.** 어떤 기술이든 자동 방어 수단으로 바꿔, 왕이 곶에 더 오래 머물 수 있게 한다.

### 8.7 공명 — 태그를 모으면 생기는 힘

노드·룬·성물·시설에는 모두 태그가 붙어 있다. 같은 태그를 3 / 6 / 9개 모으면 공명이 켜진다. 태그는 8종이다.

| 태그 | 3개 | 6개 | 9개 |
|---|---|---|---|
| 연쇄 | 연쇄 대상 +1 | 연쇄할 때마다 피해 소폭 증가 | 연쇄가 같은 적을 다시 칠 수 있다 |
| 설치 | 설치물 지속 증가 | 설치물이 왕의 인장을 이어받는다 | 왕이 성벽을 비운 동안 설치물 강화 |
| 추락 | 낙하 피해 증가 | 떨어진 적이 아래 적을 함께 떨어뜨린다 | 추락사한 적이 마정 조각을 떨어뜨린다 |
| 수호 | 성벽 수리 효율 증가 | 성벽이 맞으면 가시 반격 | 성벽 내구도가 낮을수록 왕이 강해진다 |
| 표식 | 표식 대상 피해 증가 | 시설이 표식 대상을 우선한다 | 표식 대상 처치 시 주변에 표식 전파 |
| 지대 | 지대 범위 증가 | 겹친 지대가 서로 강화 | 지대 안의 적은 등반 속도 대폭 감소 |
| 소환 | 소환수 체력 증가 | 소환수가 왕의 인장을 이어받는다 | 소환수가 쓰러지면 폭발한다 |
| 처형 | 약해진 적에게 피해 증가 | 처형 시 재사용 대기 단축 | 처형한 적이 주변 적을 겁먹게 해 등반을 늦춘다 |

### 8.8 부형태 — 두 번째 형태의 그림자

3장을 넘기면 레갈리아가 **고르지 않은 형태 하나의 가지 하나**를 부형태로 받아들인다. 부형태 기술은 한 칸에만 장착한다.

- 예: 검(주) + 활의 '사냥' → 덫을 깔고 표식을 찍은 뒤 패링으로 마무리하는 사냥꾼 왕.
- 예: 활(주) + 지팡이의 '결계' → 절벽면에 증폭진을 깔고 그 위로 화살비.
- 의도: 캠페인 후반에 빌드를 한 번 더 뒤집을 기회를 준다. 다음 캠페인에서 다른 형태를 고르고 싶게 만든다.

### 8.9 빌드 예시

| 빌드 | 구성 | 플레이 | 약점 |
|---|---|---|---|
| **빙결 연쇄 궁수** | 활·난사(도탄) + 서리·뇌전 인장 + 분열·반향 룬 + 피뢰탑 | 얼리고, 얼어붙은 무리 사이로 번개를 튕긴다. '전도' 반응이 핵심 | 대형 단일 적, 보스 |
| **가시 성벽 검왕** | 검·철벽 + 진명 '한 걸음도' + 성광 인장 + 수호 공명 9 | 성벽 대신 왕이 맞고, 맞을수록 강해진다. 성벽을 일부러 낮게 유지하는 줄타기 | 공중, 후방 주술사 |
| **부채의 마도왕** | 지팡이·파동 + 공허 인장 다수 + 성광 '일식'으로 상환 | 가장 높은 화력. 부채 게이지를 60% 근처에서 굴린다 | 실수 한 번이 '징수'로 이어진다 |
| **곶의 사냥꾼** | 활·사냥(덫·매) + 설치 룬 + 지팡이 '결계' 부형태 + 운반 석상 | 성벽은 덫과 설치물에 맡기고 곶에 가장 오래 머문다. 자원으로 압도 | 설치물을 부수는 적, 왕을 노리는 암살자 |
| **추락 전문가** | 검·파멸(내려찍기) + 서리 인장 + 밀침 룬 + 낙석 장치 + 추락 공명 | 일부러 높이 올라오게 두었다가 한꺼번에 떨어뜨린다 | 타이밍 실수, 공중 |

### 8.10 조합의 규모와 밸런스 원칙

- 형태 하나에서 기술 3개 선택(84가지) × 변형(64) × 인장(125) = **약 67만 가지** 기술 구성. 룬·진명·공명·부형태를 더하면 사실상 셀 수 없다.
- 그러나 목표는 숫자가 아니다. **형태당 뚜렷이 다른 플레이 원형 12~15개**가 성립하는 것이 목표다.
- 모든 효과는 데이터로 정의하고 태그로 상호작용시킨다. 개별 조합을 하드코딩하지 않는다.
- 진명은 반드시 대가를 갖는다. 대가 없는 진명은 수동 노드로 내린다.
- 압도적으로 강한 조합이 나오는 것을 막지 않는다. 찾아낸 플레이어의 보상이다. 다만 그 조합 하나가 모든 상황의 답이 되면 고친다.

## 9. 성 — 방어 시설과 왕 강화

**성도 왕도 영구히 쌓인다(확정).** 지은 시설, 올린 강화, 복구한 성벽은 캠페인 내내 남는다. 초기화되는 것은 없다. 플레이어는 반쯤 무너진 성 하나를 다섯 장에 걸쳐 요새로 키운다.

모든 것이 쌓이는 게임에서 긴장을 지키는 장치는 세 가지다.

| 장치 | 내용 |
|---|---|
| **끝이 있는 자원** | 곶의 매장량으로는 각성·성·왕을 모두 끝까지 올릴 수 없다 |
| **장별 상한** | 시설과 왕 강화의 단계는 그 장이 열어 주는 데까지만 오른다 |
| **쌓이는 위협** | 장이 끝날 때마다 성은 상처를 하나씩 얻는다 ([13.1](#131-같은-성-달라지는-전장)) |

### 9.1 성벽

| 항목 | 규칙 |
|---|---|
| 내구도 | 성 전체에 하나(기준 1,000). 0이 되면 함락 |
| 수리 | 흑철 1개로 내구도 50. 고요 중에만 가능 |
| 장이 끝나면 | 백성이 성벽을 고친다. 내구도가 가득 찬다 |
| 강화 | 5단계. 최대 내구도와 피해 경감. 영구 |
| 구역 복구 | 성은 무너진 채로 시작한다. 장마다 구역이 복구되어 시설 슬롯이 늘어난다 |

### 9.2 방어 시설

- **슬롯:** 1장 3칸에서 5장 8칸까지 늘어난다. 시설은 11종이고 같은 시설을 여러 칸에 지을 수 있다. 전부 지을 수는 없다.
- **단계:** 시설마다 3단계까지 올리고, 그 위에서 **특화** 둘 중 하나를 고른다. 특화는 시설의 성격을 바꾼다.
- **지은 것은 남는다.** 다음 장에도 그 자리에 그 단계로 서 있다.

| 시설 | 효과 | 특화 (둘 중 하나) | 태그 | 열리는 장 |
|---|---|---|---|---|
| 망루 | 경보를 앞당긴다. 다음 습격의 구성과 경로를 미리 보여 준다 | **봉화** — 곶 어디서나 성벽 상황이 또렷하다 / **감시병** — 바위턱의 석궁수를 망루가 먼저 쏜다 | — | 1 |
| 발리스타 | 느리고 강한 자동 사격. 표식 대상을 우선한다 | **연발** — 빠르게 여러 발 / **작살** — 맞은 적을 끌어내려 떨어뜨린다 | 표식 | 1 |
| 가시 난간 | 성벽 가장자리에 닿은 적에게 피해, 등반 지연 | **칼날** — 피해 대폭 증가 / **덩굴** — 닿은 적을 잠시 붙잡아 둔다 | 수호 | 1 |
| 수리 작업대 | 고요 중 성벽을 천천히 자동 수리 | **돌장이** — 습격 중에도 수리한다 / **보강** — 최대 내구도 증가 | 수호 | 1 |
| 기름 솥 | 구역 아래로 쏟는다. 화염 인장이 닿으면 불타는 지대가 된다 | **끓는 납** — 대형 적에게 큰 피해 / **넓은 솥** — 범위와 지대 지속 증가 | 지대 | 2 |
| 성문 방책 | 부서진 성문에 세운다. 성문길의 적을 막고 늦춘다 | **철문** — 훨씬 오래 버틴다 / **함정문** — 문 앞 구덩이로 적을 떨어뜨린다 | 수호 | 2 |
| 광차 선로 | 뒷문에서 곶으로 선로를 깐다. 선로 위 이동 시간 절반, 운반 한도 2배 | **급행** — 선로 위에서 더 빠르다 / **짐차** — 떨어진 자원을 스스로 실어 온다 | — | 2 |
| 성광 등대 | 공중 적을 늦추고 낙인을 찍는다 | **탐조** — 비춘 공중 적을 떨어뜨린다 / **정화** — 낙인 대상 처치 시 성벽 회복 증가 | — | 3 |
| 피뢰탑 | 주기적 낙뢰. 뇌전 연쇄의 중계점이 된다 | **폭풍** — 낙뢰가 잦아진다 / **사슬** — 연쇄 수 증가 | 연쇄 | 3 |
| 낙석 장치 | 수동 발동. 한 경로 전체에 추락 유발. 재장전에 흑철 소모 | **눈사태** — 모든 절벽면에 떨어진다 / **채석** — 재장전에 흑철이 들지 않는다 | 추락 | 4 |
| 증폭 제단 | 양옆 시설의 위력을 올린다. 어디에 무엇을 둘지가 중요해진다 | **공명석** — 양옆 시설의 태그를 하나 더 센다 / **집중** — 한쪽 시설만 두 배로 올린다 | — | 4 |

시설은 왕의 빌드와 맞물려야 가치가 커진다. (예: 표식 빌드 + 발리스타, 뇌전 빌드 + 피뢰탑, 추락 빌드 + 작살 발리스타)

**종은 시설이 아니다.** 오르벤이 치는 성의 일부이며 기본 경보(습격 15초 전)를 맡는다. 4장 끝에 무너진다. 망루는 그 뒤에도 남으므로, 망루에 투자한 플레이어는 5장에서도 그만큼 미리 안다.

### 9.3 왕 강화

| 축 | 효과 | 단계 |
|---|---|---|
| 다리 | 이동 속도 (단계당 10%) | 5 |
| 등 | 운반 한도 (기본 16, 단계당 +7) | 5 |
| 눈 | 해무 속 빛의 반경, 광맥 탐지 | 5 |
| 심장 | 체력, 재기 시간 단축, 왕의 귀환 효과 증가 | 5 |

성광석으로 올린다. 영구다. 채굴 위력은 왕 강화가 아니라 **레갈리아의 줄기 노드**에 있다. 무기가 강해져야 멀리 나아갈 수 있다.

### 9.4 장별 상한

| 장 | 시설 슬롯 | 시설 단계 상한 | 왕 강화 단계 상한 |
|---|---|---|---|
| 1장 | 3 | 1 | 2 |
| 2장 | 4 | 2 | 3 |
| 3장 | 6 | 3 | 4 |
| 4장 | 7 | 특화 | 5 |
| 5장 | 8 | 특화 | 5 |

상한은 앞서 벌어 둔 플레이어가 다음 장을 미리 끝내 버리는 것을 막는다. 장이 열리면 올릴 곳이 다시 생긴다.

### 9.5 되돌리기

자원에 끝이 있고 투자가 영구이므로, 잘못 쓴 자원이 캠페인을 막아서는 안 된다.

| 대상 | 규칙 |
|---|---|
| 각성 트리 | 고요 중 왕좌에서 무제한 무료 재배치 |
| 시설 철거 · 특화 변경 · 왕 강화 되돌리기 | 고요 중 왕좌에서. 쓴 자원을 전액 돌려받는다. 장마다 3회 |

횟수 제한은 습격마다 시설을 갈아 끼우는 플레이를 막기 위한 것이다.

## 10. 자원과 경제

수치의 근거와 주기별 시뮬레이션은 [경제·밸런스 시트](./04_balance.md)에 있다. 이 장은 구조와 결론만 적는다.

### 10.1 자원

모든 자원은 캠페인 내내 유지된다. 그리고 **곶에 묻힌 양이 전부다.**

| 자원 | 희귀도 | 얻는 곳 | 쓰는 곳 | 캠페인 전체 |
|---|---|---|---|---|
| **성광석** | 흔함 | 곶 전역 | 각성 노드, 왕 강화, 부채 상환 | 1,450 |
| **흑철** | 보통 | 둘째 구간부터, 단단한 암반 뒤 | 성벽 수리·강화, 시설 건설·강화 | 600 |
| **룬 수정** | 희귀 | 2장의 땅부터, 먼 구간 | 진명, 소켓 개방, 룬 강화 | 32 |
| **마정** | — | 엘리트·보스 처치 | 인장 강화 | 25 |
| **대파편** | 장당 1개 | 각 땅 끝자락의 낙성지 | 장의 목표, 각성 단계 개방 | 5 |

### 10.2 세 갈래의 지출 경쟁

```
        성광석                  흑철                  성광석
          │                      │                      │
          ▼                      ▼                      ▼
     레갈리아 각성          성 (시설·성벽)            왕 강화
   싸움과 채굴 양쪽의 힘   왕이 없어도 버티는 힘    채굴 효율 = 복리
```

세 축 모두 영구다. 그래서 질문은 "이번 장을 어떻게 넘길까"가 아니라 **"이 캠페인에서 무엇을 끝까지 키울까"**다.

- **성광석**은 각성과 왕 강화가 나눠 쓴다. 매장량은 둘을 모두 끝까지 올리는 비용의 53%다.
- **흑철**은 수리와 시설이 나눠 쓴다. 성벽이 많이 맞을수록 시설에 쓸 흑철이 줄어든다. 잘 싸우는 것이 곧 투자다.
- **초반:** 왕 강화(복리)가 가장 이득이지만, 다음 습격을 못 막으면 의미가 없다.
- **중반:** 시설로 성벽을 안정시킬수록 곶에 오래 머문다.
- **후반:** 땅끝 너머에는 캘 것이 없다. 남은 자원을 어디에 쓸지가 마지막 결정이다.

### 10.3 시뮬레이션 결론 (가설)

| 진행 방식 | 성광석 채집 | 깨운 노드 (69개 중) | 왕 강화 (20단계 중) | 시설 (32단계 중) |
|---|---|---|---|---|
| 표준 | 1,274 (매장량의 88%) | 38 | 13 | 18 |
| 채굴 우선 (왕 강화 먼저) | 1,440 (99%) | 26 | 18 | 20 |
| 무기 우선 (왕 강화 거의 없음) | 904 (62%) | 40 | 2 | 13 |

- 어느 쪽으로 가도 전부를 가질 수는 없다. 표준 진행은 트리의 55%를 깨운다.
- **왕 강화를 건너뛰는 것은 함정이다.** 무기에 몰아 써도 노드는 표준보다 2개 많을 뿐이고, 매장량의 3분의 1 이상을 땅에 남긴다. 진짜 선택은 "채굴이냐 무기냐"가 아니라 **"언제 채굴에서 무기로 넘어가느냐"**다.
- 노드 비용은 단계별 8 / 14 / 22 / 34 / 50이다. 진명 32(+룬 수정 2), 궁극 48, 궁극 진화 60, 교차 18 / 40.

## 11. 곶 탐사

### 11.1 곶의 다섯 땅

성 뒤편에서 바다까지, 장마다 한 땅씩 열린다. 레갈리아가 부서질 때 큰 조각일수록 멀리 날아갔다. 그래서 뒤로 갈수록 값진 것이 묻혀 있다.

| 땅 | 열리는 장 | 풍경 | 특징 |
|---|---|---|---|
| 1. 옛 채석장 | 1장 | 성벽을 쌓을 돌을 캐던 곳. 깎인 바위, 버려진 수레 | 무른 암반, 옅은 안개. 채굴의 기본을 익힌다 |
| 2. 왕릉 언덕 | 2장 | 역대 왕의 무덤과 석비 | 봉인실이 많다(성물·룬). 낙석. 룬 수정이 나오기 시작한다 |
| 3. 별 떨어진 분지 | 3장 | 옛날 별이 떨어져 파인 땅. 수정 기둥 | 성광석이 풍부하다. 불안정한 결정, 마계 침식의 시작 |
| 4. 해무의 황야 | 4장 | 짙은 안개, 바람, 소금기 | 시야가 좁고 종소리가 멀다. 밀물이 들기 시작한다 |
| 5. 땅끝 | 5장 | 바다 절벽과 갯바위. 첫 모루 | 밀물과 썰물, 가장 단단한 암반. 그 너머는 바다 |

땅마다 풍경만이 아니라 **캐는 방식**이 달라야 한다. 채석장은 넓게 파고, 왕릉은 방을 찾아 들어가고, 분지는 결정을 터뜨려 길을 내고, 황야는 안개 속을 더듬고, 땅끝은 물때에 맞춰 드나든다.

### 11.2 생성

- 1타일은 2m다. 땅 하나는 폭 24타일 × 길이 36타일(48m × 72m)이고, 길이 방향으로 12타일씩 세 구간으로 나뉜다. 성에서 먼 구간일수록 암반이 단단하고 자원이 많다.
- 절차적 생성으로 암반과 광맥을 깔고, 손으로 만든 '자리'를 끼워 넣는다. 생성의 순서, 검증 조건, 만들어 본 땅의 측정값은 [곶 생성 규칙](./07_cape_generation.md)에 있다.
- 광맥은 드물고 진하다. 타일 하나에서 5~9개가 나오고 2~4타일씩 덩어리져 있다. 덩어리 하나가 고요 한 번의 짐이다.
- 대파편이 떨어진 낙성지는 항상 그 땅의 가장 먼 구간에 있다. 위치는 매번 다르다.
- **곶의 자원은 유한하다.** "전부 가질 수 없다"는 규칙을 땅의 크기가 보장한다.
- 땅의 크기는 프로토타입에서 다시 정한다. 탐사의 기대가 약하면 넓히고, 걷는 시간이 지루하면 좁힌다.

### 11.3 타일

| 타일 | 강도 | 비고 |
|---|---|---|
| 흙·자갈 | 12 | 가까운 구간 대부분 |
| 연암 | 30 | — |
| 경암 | 80 | 채굴 위력을 올리지 않으면 시간 낭비 |
| 흑암 | 180 | 4장의 땅부터. 채굴 위력 Ⅲ이 있어야 깎인다 |
| 광맥 | 암반과 같음 | 성광석·흑철·룬 수정 |
| 바위산 | 파괴 불가 | 땅의 뼈대, 길을 강제한다 |
| 바다 | 통과 불가 | 곶의 좌우와 끝. 세계의 경계 |

강도는 채굴 위력 1의 타격으로 깎는 횟수다. 타격은 0.3초에 한 번이고, 채굴 위력이 오르면 타격당 깎는 양이 늘어난다.

### 11.4 자리

| 자리 | 내용 | 수 |
|---|---|---|
| **봉인실** | 돌로 봉한 옛 석실. 성물 또는 룬 셋 중 하나를 고른다 | 땅당 3~4개 |
| **낙성지** | 대파편이 떨어져 파인 구덩이. 들어 올리는 순간 총공세가 예고된다 | 땅당 1개 |
| 옛 왕의 석관 | 숨은 기억 조각. 진결말의 조건 | 땅당 1개 |
| 샘 | 마시면 다음 습격 동안 지속되는 강화를 얻는다. 한 번 쓰면 마른다 | 땅당 1~2개 |
| 옛 길 | 구간을 가로지르는 지름길. 찾아내면 귀환이 빨라진다 | 땅당 1개 |

### 11.5 위험 — 전투는 없다, 환경만 있다

| 위험 | 내용 | 이용법 |
|---|---|---|
| 해무 (전 구간) | 바다에 가까울수록 짙다. 시야가 줄고 종소리가 작아진다 | 빛의 반경 강화, 성물 '메아리 종' |
| 낙석 (2장부터) | 비탈의 바위가 굴러 판 길을 막는다 | 받침 바위를 남기며 판다. 일부러 굴려 암반을 부순다 |
| 불안정한 결정 (3장부터) | 터지면 주변 타일과 왕에게 피해 | 일부러 터뜨려 넓게 판다 |
| 마계 침식 (3장부터) | 타일이 서서히 번지며 광맥을 오염시킨다 | 성광 인장으로 정화하면 자원 추가 |
| 밀물 (4장부터) | 주기적으로 물이 차올라 낮은 타일이 잠기고 길이 끊긴다 | 썰물 때만 드러나는 광맥이 있다 |

밀물은 종소리와 별개로 도는 두 번째 시계다. 4장부터는 "습격까지 남은 시간"과 "물이 차기까지 남은 시간"을 함께 읽어야 한다.

### 11.6 운반

- 캔 자원은 바닥에 떨어진다. 다가가면 '빛의 실'에 꿰여 왕을 따라온다.
- 운반 한도는 기본 16조각이다. 한도의 절반을 넘으면 조각마다 느려진다. 무엇을 두고 갈지 고르는 것이 귀환 판단의 일부다.
- 뒷문에 닿으면 수령된다. 쓰러지거나 급히 버리면 그 자리에 남는다.

### 11.7 길 — 지나온 땅은 가까워진다

| 수단 | 내용 | 지속 |
|---|---|---|
| 판 자리 | 한 번 판 길은 다시 막히지 않는다 | 캠페인 내내 |
| 닦인 길 | 장을 끝낸 땅에는 길이 난다. 길 위에서는 3배 빠르다 (땅 하나를 4초에 통과) | 캠페인 내내 |
| 옛 길 | 찾아낸 지름길 | 캠페인 내내 |
| 광차 선로 | 시설. 선로 위 이동 시간 절반, 운반 한도 2배 | 캠페인 내내 |

### 11.8 성물 (봉인실 택1)

출시 시점 15종. 얻은 성물은 모두 남지만 **동시에 가동할 수 있는 것은 5개**다. 고요 중 왕좌에서 바꿔 끼운다.

| 성물 | 효과 |
|---|---|
| 길잡이 실타래 | 뒷문으로 즉시 귀환. 주기당 1회 |
| 운반 석상 | 떨어진 자원을 뒷문까지 스스로 나른다 |
| 메아리 종 | 곶 어디서나 경보를 또렷이, 더 일찍 듣는다. 성벽 상황을 본다 |
| 광부의 눈 | 주변 광맥이 암반 너머로 보인다 |
| 잠들지 않는 궁수상 | 슬롯을 쓰지 않는 자동 사격 시설 |
| 성광 화로 | 성광석을 태워 성벽을 수리한다 |
| 지진 쐐기 | 현재 구간 전체의 암반 강도를 한 단계 낮춘다 |
| 썰물의 뿔피리 | 밀물을 한 번 물린다. 주기당 1회 |
| 깨진 모래시계 | 고요가 길어지고, 그만큼 습격이 거세진다 |
| 왕의 발자국 | 성벽을 비운 시간이 길수록 왕의 귀환이 강해진다. 상한이 두 배가 된다 |

## 12. 적과 습격

### 12.1 습격의 규칙

```
  고요 (100초, 4장부터 85초)  →  경보: 종 (습격 15초 전)  →  습격 (55~75초, 전멸 시 종료)  →  고요 …
```

| 규칙 | 내용 |
|---|---|
| 장의 길이 | 정규 습격 12회, 그리고 총공세 1회 |
| 왕이 곶에 나가 있어도 | 습격은 시작된다. 시설만이 버틴다 |
| 빨리 끝낼수록 | 다음 고요가 빨리 시작된다. 전투 실력이 곧 채굴 시간이다 |
| **흠 없는 방어** | 성벽이 피해를 받지 않고 습격이 끝나면 다음 고요가 10초 길어진다. 잘 싸운 값이 채굴 시간으로 돌아온다 |
| 강도 | 습격마다 '위협 예산'이 9%씩 늘고, 예산으로 적을 산다. 장이 바뀌면 직전의 80%로 낮아졌다가 다시 오른다 |
| 엘리트 습격 | 장의 6번째와 12번째. 엘리트가 마정을 떨어뜨린다 |
| 장의 사건 | 장의 가운데에 한 번. 그 장만의 일이 벌어진다 ([13.2](#132-장의-사건)) |
| 총공세 | 대파편을 성으로 가져오면 시작. 마지막 습격의 1.5배 규모에 보스가 온다 |

위협 예산은 1장 첫 습격 10에서 5장 마지막 습격 128까지 약 13배로 자란다. 전체 표는 [경제·밸런스 시트](./04_balance.md)에 있다.

### 12.2 접근 경로

| 경로 | 열리는 때 | 오는 적 | 대응 |
|---|---|---|---|
| 중앙 절벽면 | 처음부터 | 등반하는 다수 | 세 형태 모두의 주 전장 |
| 바위턱 | 처음부터 | 절벽 중턱에 자리 잡는 원거리 적 | 원거리 수단 또는 설치물 |
| 성문길 | 1장 보스전, 2장부터 상시 | 느리고 단단한 중장갑·공성 병기 | 집중 화력, 성문 방책, 낙석·기름 |
| 좌 절벽면 | 3장부터 | 등반하는 다수. 중앙과 동시에 온다 | 한쪽을 설치물과 시설에 맡긴다 |
| 공중 | 3장부터 | 시설을 노리는 비행체 | 성광 등대, 범위기 |

### 12.3 추락 — 이 게임만의 전투 규칙

- 등반 중인 적에게는 **붙잡기** 수치가 있다. 밀어내는 힘을 받으면 깎이고, 0이 되면 떨어진다.
- 낙하 피해는 **높이의 제곱**에 비례한다. 낮은 곳에서 떨어진 적은 살아남아 다시 오르고, 턱밑에서 떨어진 적은 죽는다.
- 떨어지는 적은 같은 레인에서 바로 아래의 적 하나를 덮친다. 덮친 적도 떨어지면 연쇄가 이어진다. 기본으로는 잘 이어지지 않고, 빙결·노드·공명이 연쇄를 만든다.
- 빙결·속박 상태의 적은 붙잡기가 크게 약해진다.

수치와 계산 표는 [전투 규칙](./06_combat_rules.md)에 있다.

**높이의 딜레마:** 낮은 곳에서 잡으면 안전하지만 추락 이득이 없다. 성벽 턱밑까지 올라오게 두면 위험하지만, 떨어뜨릴 때 한 줄을 통째로 쓸어 낸다. 활은 전자, 검은 후자에 가깝고, 빌드에 따라 뒤집을 수 있다.

## 13. 챕터 구성

장이 바뀌어도 초기화되는 것은 없다. 장은 **새 땅, 새 적, 새 경로, 새 상한, 그리고 그 장만의 사건**으로 구분된다.

| 장 | 곶의 땅 | 새 적 | 새 시스템 | 장 끝에 성이 얻는 상처 | 시간 |
|---|---|---|---|---|---|
| 프롤로그 | — | 등반병 | 형태 선택, 전투 기본, 종소리 | — | 15분 |
| 1장 | 옛 채석장 | 방패병, 석궁수, 사다리조 | 채굴·운반, 시설, 성물, 각성 1단계 | **성문이 부서진다** | 48분 |
| 2장 | 왕릉 언덕 | 공성병, 되살아난 자, 그림자 칼, 짐꾼 거인 | 인장, 룬과 소켓, 둘째 기술과 변형, 석관, 낙석 | **서쪽 벼랑에 길이 난다** | 50분 |
| 3장 | 별 떨어진 분지 | 벽 기는 것, 날개 임프, 부식충, 균열 주술사 | 진명, 셋째 기술, 공중 경로, 결정과 침식, 엘리트 수식어 → 클리어 후 공허·부형태 | **균열이 닫히지 않는다** | 51분 |
| 4장 | 해무의 황야 | 절벽 거수, 발카르 | 궁극기, 시설 특화, 짙은 해무, 밀물 | **종탑이 무너진다** | 50분 |
| 5장 | 땅끝 · 첫 모루 | 심연의 손, 심연의 권속 | 궁극 진화, **종 없음**(경보가 레갈리아의 떨림으로 바뀌고 8초로 짧아진다), 진명 해방 | — | 51분 |

시간은 왕좌 메뉴를 포함한 순수 진행 시간이다. 다섯 장 합계 약 4시간 10분이고, 프롤로그·컷신·재도전을 더해 첫 클리어 6~8시간을 목표로 한다.

### 13.1 같은 성, 달라지는 전장

성은 하나다. 왕이 쌓은 것이 남는 것처럼, 적이 낸 상처도 남는다. 장마다 지킬 곳이 늘어난다.

| 장 | 열려 있는 경로 | 시설 슬롯 | 전장의 모습 |
|---|---|---|---|
| 1장 | 중앙 절벽면, 바위턱 (성문길은 보스전에만) | 3 | 반쯤 무너진 성. 지킬 곳이 좁다 |
| 2장 | + 성문길 상시 | 4 | 부서진 성문으로 중장갑이 걸어 들어온다 |
| 3장 | + 좌 절벽면, 공중 | 6 | 성벽 양 끝을 오가야 한다. 하늘이 붉어진다 |
| 4장 | 전부. 고요가 100초에서 85초로 짧아진다 | 7 | 균열에서 증원이 끊이지 않는다 |
| 5장 | 전부. 종이 없다 | 8 | 경보가 짧다. 심연의 주인이 벼랑 전체를 덮는다 |

### 13.2 장의 사건

장마다 가운데(여섯 번째 습격 무렵)에 한 번, 그 장에서만 벌어지는 일이 있다. 같은 주기가 열두 번 되풀이되는 것을 끊고, 장마다 기억에 남는 장면을 하나씩 남긴다.

| 장 | 사건 | 벌어지는 일 |
|---|---|---|
| 1장 | **사절** | 발카르의 사절이 성문 앞에 와서 항복을 권한다. 대답은 정해져 있다. 그 고요는 절반으로 줄고, 이어지는 습격이 첫 엘리트 습격이다 |
| 2장 | **묘역의 안개** | 해무가 성벽까지 밀려온다. 한 번의 습격 동안 절벽 아래가 보이지 않는다. 적은 턱밑에 와서야 드러난다 |
| 3장 | **별이 진다** | 곶에 새 유성이 떨어진다. 큰 광맥이 생기지만 그 고요는 짧다. 가면 늦고, 안 가면 아깝다 |
| 4장 | **큰 밀물** | 한 번의 고요 동안 곶의 절반이 잠긴다. 물이 빠지면 평소에는 없던 광맥이 드러난다 |
| 5장 | **마지막 등불** | 백성들이 성벽에 등불을 건다. 한 번의 습격 동안 모든 시설이 한 단계 위로 움직인다 |

### 13.3 장의 곡선은 어디서 오는가

매 판 처음부터 시작하지 않으므로, 장마다의 '약함에서 강함으로'는 초기화가 아니라 **새 구멍**에서 만든다.

| 장의 구간 | 벌어지는 일 |
|---|---|
| 초반 | 새 경로와 새 적이 지금까지의 방어에 구멍을 낸다. 어제의 요새가 오늘은 모자라다 |
| 중반 | 새 땅의 자원으로 구멍을 메운다. 상한이 풀린 시설과 강화를 올린다. 장의 사건이 온다 |
| 후반 | 대파편으로 각성의 새 단계가 열린다. 새 힘을 들고 총공세와 보스를 맞는다 |

## 14. 진행 · 실패 · 난이도 · 모드

### 14.1 쌓은 것은 남는다

캠페인에서 **초기화되는 것은 없다(확정).**

| 영구히 남는 것 | 내용 |
|---|---|
| 레갈리아 | 각성 트리, 인장, 룬, 진명, 부형태 |
| 성 | 방어 시설과 그 단계·특화, 성벽 강화, 복구한 구역 |
| 왕 | 왕 강화 |
| 곶 | 판 자리, 닦인 길, 옛 길, 광차 선로 |
| 자원과 수집물 | 성광석, 흑철, 룬 수정, 마정, 성물, 기억 조각 |
| 성의 상처 | 부서진 성문, 서쪽 벼랑의 길, 닫히지 않는 균열, 무너진 종탑 |

장이 끝날 때 회복되는 것은 **성벽 내구도** 하나다.

### 14.2 실패

- **함락**(성벽 내구도 0) → **되감기.** 마지막 고요의 시작, 또는 그 장의 시작 중에서 고른다. 그 시점 이후의 자원·강화·지형은 모두 그 시점으로 돌아간다.
- "패배해도 얻은 것은 남는다"는 규칙은 두지 않는다. 자원에 끝이 있으므로, 남기면 자원이 복제된다.
- **결의:** 같은 장에서 함락될 때마다 성벽 최대 내구도가 5% 오른다(최대 3회). 장을 넘기면 사라진다. 막힌 플레이어를 자원 없이 돕는 장치다.
- 그래도 막히면 [되돌리기](#95-되돌리기)로 투자를 다시 짜거나 난이도를 낮춘다.

### 14.3 저장

- 고요가 시작될 때마다 자동 저장. 장 시작 시점은 따로 보관한다.
- 저장 후 종료 가능. 캠페인 슬롯 3개. 농성은 한 판을 중간에 저장하고 이어 할 수 있다.

### 14.4 난이도

| 난이도 | 위협 예산 | 고요 길이 | 대상 |
|---|---|---|---|
| 이야기 | 낮음 | 김 | 이야기와 빌드 실험을 즐기려는 플레이어 |
| 표준 | 기준 | 기준 | 기본값 |
| 농성 | 높음 | 짧음 | 돔 키퍼류 숙련자 |

난이도는 고요 중 언제든 바꿀 수 있다. 그 위의 난이도는 [서약](#147-서약)으로 스스로 만든다.

### 14.5 모드

| 모드 | 내용 | 해금 |
|---|---|---|
| **캠페인** | 프롤로그 + 5장. 이야기가 있고 모든 성장이 영구 누적된다 | 처음부터 |
| **농성** | 캠페인과 별개의 한 판. 빈 성과 새로 생성된 곶에서 시작해 40~60분 안에 요새를 세우고 버틴다 | 캠페인 1장 클리어 |
| **다시 깨어남** | 캠페인을 처음부터 다시. 다른 형태를 고르고, 서약을 걸고, 적 구성이 바뀐다 | 캠페인 클리어 |

두 모드는 같은 재료를 다른 호흡으로 쓴다. 캠페인은 하나의 빌드를 여덟 시간에 걸쳐 키우고, 농성은 한 시간에 하나씩 새 빌드를 시험한다. 캠페인에서 형태를 바꿀 수 없는 아쉬움을 농성이 받아 준다.

### 14.6 농성

돔 키퍼식 '빈손에서 요새까지'를 한 판에 담는 모드다. 조합이 깊은 게임일수록 짧게 여러 번 해 볼 자리가 필요하다.

| 항목 | 규칙 |
|---|---|
| 시작 | 형태, 성의 배치, 서약을 고른다. 빈 성과 새로 생성된 곶 |
| 곶 | 땅 하나가 다섯 구간으로 길게 뻗어 있고 끝은 바다다. 구간마다 캠페인의 다섯 땅의 성격을 차례로 띤다 |
| 목표 | 땅끝의 대파편을 성으로 가져와 총공세를 막는다. 이긴 뒤에는 그만두거나 **끝없이 버티기**를 고른다 |
| 성장 | 각성 트리의 모든 단계가 처음부터 열려 있다. 막는 것은 자원뿐이다. 한 판 안에서 1단계부터 궁극기까지 간다 |
| 줍는 것 | 인장·룬·성물은 봉인실에서 무작위 셋 중 하나. 판마다 손에 쥐는 재료가 달라 빌드가 달라진다 |
| **징조** | 습격 네 번마다 둘 중 하나를 고른다. 거센 습격과 큰 보상, 또는 무난한 습격 |
| 적 | 캠페인의 모든 적이 위협 예산에 따라 섞여 나온다. 경로는 습격이 거듭되며 하나씩 열린다 |
| 끝없이 버티기 | 곶의 자원은 유한하다. 썰물 때마다 땅끝 해안에 새 성광석이 밀려온다. 멀리 가야 얻는다 |
| 판을 거듭하며 여는 것 | 새 서약, 시작 성물의 후보, 성의 배치(넓은 성벽 / 쌍둥이 탑 / 원형 첨탑). **수치를 올려 주는 영구 강화는 없다.** 쌓이는 것은 플레이어의 지식이다 |
| 겨루기 | 순위표, 일일·주간 시드 |

### 14.7 서약

스스로 거는 제약이다. 농성과 '다시 깨어남'에서 건다. 걸수록 어려워지고, 점수 배율과 해금이 따라온다. 레갈리아는 왕의 서약을 기억한다는 설정과 맞닿아 있다.

| 서약 | 제약 |
|---|---|
| 침묵의 서약 | 종이 울리지 않는다 |
| 빈 벽의 서약 | 시설 슬롯이 절반이다 |
| 외길의 서약 | 가지 하나만 깨울 수 있다 |
| 돌아보지 않는 서약 | 재배치와 되돌리기를 쓸 수 없다 |
| 빚의 서약 | 처음부터 공허 인장을 지니고, 부채가 절반 차 있다 |
| 밀물의 서약 | 첫 구간부터 밀물이 든다 |
| 굶주린 땅의 서약 | 매장량이 4분의 1 줄어든다 |
| 왕 혼자의 서약 | 성물을 쓸 수 없다 |

출시 시점 12종 안팎. 여러 개를 함께 걸 수 있다.

## 15. UI / UX

화면마다의 배치와 요소, 상태, 입력은 [화면 설계서](./09_screen_design.md)에 있다. 이 장은 원칙만 적는다.

### 15.1 HUD

```
┌────────────────────────────────────────────────────────────────┐
│ 성벽 ████████░░           (종) 다음 습격 0:47       성광석 124   │
│                                                흑철 18  룬수정 3 │
│                                                                │
│                         ( 게임 화면 )                           │
│                                                                │
│ 왕 ████░   부채 ░░░                                             │
│ [기본] [기술1] [기술2] [기술3] [궁극]         운반 3/5   [지도]   │
└────────────────────────────────────────────────────────────────┘
```

| 요소 | 원칙 |
|---|---|
| **종 게이지** | 화면 위 가운데. 가장 중요한 정보다. 경보 때는 소리와 화면 테두리로도 알린다 |
| 성벽 내구도 | 항상 보인다. 곶에서도 |
| 성벽 띠 | 곶에 나가 있을 때 화면 위에 뜨는 성벽 축소도. 공격받는 구역이 깜박인다 |
| 물때 | 4장부터. 종 게이지 옆에 밀물까지 남은 시간을 함께 보여 준다 |
| 비운 시간 | 성벽을 비운 시간이 쌓이는 것을 왕 옆의 작은 고리로 보여 준다. 왕의 귀환이 얼마나 강할지 미리 안다 |
| 적의 높이 | 절벽면의 단마다 색이 다르다. 추락 가능 상태의 적은 윤곽선으로 표시 |

### 15.2 각성 트리 화면

- 별자리 형태. 깨운 별과 깨울 수 있는 별, 아직 닿지 않는 별이 한눈에 구분된다.
- **가상 투자:** 확정 전에 노드를 찍어 보고, 기술 설명과 공명 변화를 미리 본다.
- **태그 검색:** 태그를 누르면 그 태그가 붙은 노드·룬·시설이 전부 빛난다.
- **빌드 보관:** 구성을 3개까지 저장하고 불러온다.

### 15.3 온보딩

- 프롤로그 10분 안에 루프 한 바퀴(싸운다 → 나간다 → 캔다 → 종이 울린다 → 돌아온다)를 겪게 한다.
- 시스템은 장마다 하나씩 연다([13장](#13-챕터-구성)). 조합의 여섯 층을 한꺼번에 보여 주지 않는다.

### 15.4 접근성

- 속성은 색만이 아니라 아이콘 모양으로도 구분.
- 화면 흔들림·섬광 강도 조절.
- 조준 보조, 기술 꾹 누르기/전환 선택.
- 자막 크기 조절, 종소리의 시각 대체 표시.

## 16. 아트와 오디오

### 16.1 누가 무엇을 만드는가

1인 제작이므로 직접 만드는 것은 규칙과 조합, 그리고 화면을 하나로 묶는 마감에 집중한다.

| 영역 | 수단 | 내용 |
|---|---|---|
| 3D 모델·애니메이션 | Unity 에셋 스토어 | 왕, 적, 성·절벽·암반 환경. **한 계열의 팩으로 통일**한다 |
| VFX | 에셋 팩 + 색 조정 | 기술은 전달 방식 7종의 효과를 인장 5색으로 변주한다 |
| 2D 일러스트 | Midjourney | 컷신과 기억 파편의 정지 화면 약 25장, 스토어 캡슐과 키 아트 |
| 아이콘 | Midjourney + 손질 | 기술·룬·성물·시설·인장·서약 약 120개 |
| UI | 직접 제작 (UI Toolkit) | 에셋 팩을 쓰지 않는다. HUD, 왕좌 메뉴, 별자리 트리 화면을 모두 직접 만든다 |
| 음악·효과음 | 에셋 팩 | 종소리만은 따로 고른다 |
| 음성 | 미결 | 발카르와 오르벤 둘만 넣는 안을 검토한다([20장](#20-확정-사항과-미결-사항)) |
| 코드·데이터·글 | Claude | C# 코드, 노드와 습격 데이터, 대사, 영어 번역 초안 |

Midjourney는 2D에만 쓴다. 3D 모델은 만들지 않는다.

### 16.2 화면

| 항목 | 방향 |
|---|---|
| 양식 | 양식화된 3D. 굵은 실루엣. 사실적 묘사보다 **탑다운에서의 가독성** |
| 색 | 성과 왕 — 차가운 청회색에 성광의 금빛 / 카르둔 군 — 잿빛과 녹슨 붉은색 / 마계 — 자홍과 검정 |
| 성벽 | 넓고 춥고 높다. 바람, 깃발, 벼랑. 장이 지날수록 하늘이 붉어진다 |
| 곶 | 안개 낀 고요한 땅. 해무 속에서 레갈리아와 성광석만 빛난다. 다섯 땅은 색·소품·안개·위험 요소로 구분한다 |
| 바다 | 세계의 끝. 뒤로 갈수록 안개가 짙어지고 파도 소리가 커진다. 땅끝에서 처음으로 수평선이 보인다 |
| 레갈리아 | 각성할수록 모습이 변한다. 깨운 가지에 따라 날·자루·현의 부품이 바뀌고, 찍은 인장의 색을 띤다. 5장의 무기는 플레이어마다 다르게 생겼다 |
| 성의 변화 | 지은 시설과 복구한 구역이 성의 모습에 그대로 쌓인다. 상처(부서진 성문, 깎인 벼랑, 무너진 종탑)도 남는다 |
| 타격감 | 추락은 이 게임의 얼굴이다. 떨어지는 적의 궤적, 아래에서 휩쓸리는 적, 바닥의 먼지까지 화면에서 읽혀야 한다 |

**에셋을 섞어 쓴 티를 지우는 장치:** 한 제작사의 한 계열만 쓴다. 머티리얼 색을 위 팔레트로 다시 칠한다. 조명·안개·색 보정을 장면 전체에 공통으로 건다. UI와 글꼴은 고유하게 만든다.

### 16.3 일러스트

- 3D 화면과 다른 회화풍으로 간다. 컷신이 '다른 층위의 이야기'로 읽히게 한다.
- 스타일 참조 이미지를 하나 정해 모든 장면에 고정한다.
- **인물의 얼굴을 가까이 그리지 않는다.** 뒷모습, 실루엣, 원경으로 구성한다. 생성 이미지에서 같은 인물을 여러 장에 걸쳐 일관되게 유지하기 어렵기 때문이다. 이야기의 건조한 톤과도 맞는다.
- 장면 목록: 프롤로그 2, 장의 시작과 끝 10, 장의 사건 5, 기억 5, 결말 4.

### 16.4 오디오

- **종소리가 이 게임의 소리다.** 경보, UI 효과음, 음악의 주제 선율이 모두 종에서 나온다.
- 고요: 바람과 먼 파도 소리. 음악은 거의 없다. 바다에 가까워질수록 파도가 커지고 종소리는 멀어진다.
- 습격: 타악 중심. 적이 높이 올라올수록 소리의 겹이 쌓인다.
- 왕의 귀환: 성벽에 돌아오는 순간 종이 한 번 크게 운다.
- 5장: 종이 없다. 그 자리를 침묵과 레갈리아의 떨림이 채운다.

## 17. 기술과 스팀 출시

### 17.1 엔진 (확정)

**Unity 6.** 프로젝트를 시작하는 시점의 최신 LTS 판으로 고정한다. 개발이 길어지면 LTS가 바뀔 수 있다. 주 버전은 큰 마일스톤 사이에서만, 필요할 때만 올린다. 렌더 파이프라인은 URP를 기본으로 잡는다(아직 가정이다).

### 17.2 기술 과제

구조와 근거, 이미 작성한 시뮬레이션 코어는 [기술 설계서](./08_technical_design.md)에 있다.

| 과제 | 접근 |
|---|---|
| 다수 적의 등반 | 길 찾기를 쓰지 않는다. 경로마다 등반 레인을 여러 줄 두고, 적은 레인 위의 높이 값 하나로 움직인다. 화면 내 150~200기를 목표로 한다 |
| 파괴 가능한 타일 지형 | 2차원 격자 데이터와 청크 단위 메시. 판 자리는 저장해 캠페인 내내 유지 |
| 조합 시스템 | 기술·룬·인장·태그를 모두 데이터(`data/`의 JSON)로 정의. 기술은 전달 방식 7종의 조립. 조합을 하드코딩하지 않는다 |
| 규칙 데이터 | 저장소의 `data/*.json`이 원본이다. 파이썬 도구, C# 시뮬레이션, 문서가 같은 파일을 읽는다. ScriptableObject는 모델·아이콘·효과를 잇는 데만 쓴다 |
| 시뮬레이션과 화면의 분리 | 규칙은 Unity를 모르는 순수 C#(`sim/`)에 두고 Unity 없이 테스트한다. Unity는 그리기와 입력만 맡는다 |
| 절차적 곶 생성 | 시드 기반. 캠페인과 농성이 같은 생성기를 쓴다. 일일·주간 시드에도 쓴다 |
| 한 장으로 이어진 지도 | 성벽과 곶을 끊김 없이 오간다. 왕이 곶에 있는 동안에도 성벽 전투를 그대로 돌린다 |
| 저장과 되감기 | 고요 시작마다 전체 상태를 스냅샷으로 저장. 되감기는 스냅샷 불러오기다 |
| 두 모드의 공유 | 캠페인과 농성은 같은 시스템을 쓰고 규칙 데이터만 다르다(단계 상한, 위협 곡선, 땅의 구성). 모드별 코드를 따로 두지 않는다 |

### 17.3 저장소와 에셋 규칙

- **유료 에셋과 Midjourney 원본은 공개 저장소에 올리지 않는다.** 에셋 스토어 에셋은 게임에 넣어 배포하는 것은 허용되지만 원본 재배포는 허용되지 않는다. 저장소를 비공개로 두거나, 에셋 폴더를 제외한다.
- 큰 바이너리는 Git LFS로 관리한다.

### 17.4 목표 사양 (가설)

| 구분 | 목표 |
|---|---|
| 최소 | GTX 1050급, 8GB RAM, 1080p 30fps 이상 |

### 17.5 스팀 기능

업적, 클라우드 저장, 순위표(농성), 컨트롤러 완전 지원.

업적 방향: 장 클리어 / 형태별 클리어 / 진결말 / 빌드 과제("공허 인장 없이 4장 클리어", "한 습격에 30기 추락") / 서약을 건 클리어 / 농성 기록.

### 17.6 스팀 출시 절차

| 절차 | 제약 |
|---|---|

### 17.7 AI 생성물의 공개

- 스팀은 제출 시 콘텐츠 설문에서 **AI로 미리 생성한 콘텐츠**를 밝히게 하고, 그 내용을 상점 페이지에 표시한다. 본작에서는 Midjourney로 만든 일러스트와 아이콘이 해당한다.
- 코딩 보조처럼 플레이어에게 보이지 않는 내부 도구는 2026년 1월 이후 설문 대상에서 빠진 것으로 알려져 있다. 제출 전에 설문 문구를 다시 확인한다.
- Midjourney 이미지의 상업적 이용은 유료 플랜에서만 허용된다. 출시 전에 약관을 다시 확인한다.
- AI로만 생성한 이미지는 저작권 보호를 받기 어려울 수 있다. 캡슐과 키 아트는 직접 손을 대 합성·보정한 결과물로 만든다.

## 18. 범위와 만드는 순서

### 18.1 출시 범위

| 항목 | 프로토타입 | 버티컬 슬라이스 | 1.0 |
|---|---|---|---|
| 형태 | 1 (검) | 1 (검, 완성 품질) | 3 |
| 능동 기술 | 3 | 검의 9개 중 6 | 형태당 9 + 궁극 3 (합계 36) |
| 각성 노드 | 8 | 검 1~3단계 | 형태당 69 (합계 207) |
| 인장 | 0 | 3 | 5 (반응 10) |
| 룬 | 0 | 6 | 20 |
| 성물 | 2 | 6 | 15 |
| 방어 시설 | 3 | 6 | 11종 × 3단계 + 특화 22 |
| 왕 강화 | 4축 × 2단계 | 4축 × 3단계 | 4축 × 5단계 |
| 적 | 4 | 8 | 15 + 징수꾼 + 엘리트 수식어 4 |
| 보스 | 0 | 2 | 5 |
| 땅 | 1 | 2 | 5 |
| 장 | 1장의 회색 상자 | 프롤로그 + 1~2장 | 프롤로그 + 5장, 장의 사건 5 |
| 모드 | — | 캠페인 일부 | 캠페인, 농성, 다시 깨어남 |
| 서약 | — | — | 12 |

### 18.2 만드는 순서

날짜를 정하지 않는다. 대신 **각 단계가 끝날 때마다 그 자체로 온전히 플레이되는 한 겹**이 남게 한다. 재미가 확인된 것 위에만 다음을 쌓는다.

| 단계 | 만드는 것 | 넘어가는 기준 |
|---|---|---|
| **1. 프로토타입** | 검, 성, 땅 하나, 적 4종, 고요와 습격의 주기. 회색 상자 | [프로토타입 사양서](./03_prototype_spec.md)의 여섯 질문에 답한다. 아니면 여기서 설계를 고친다 |
| **2. 버티컬 슬라이스** | 검 하나로 프롤로그와 1~2장을 출시 품질로. 각성 트리와 화면, 인장, 룬, 시설, 저장과 되감기. 에셋 적용, 보스 둘 | 외부 사람이 설명 없이 2장까지 끝내고 다시 하고 싶어 한다. **"쌓였는데도 2장 초반에 긴장이 되살아나는가"**에 답한다 |
| **3. 농성 모드** | 같은 재료로 한 판짜리 모드를 먼저 세운다. 징조, 끝없이 버티기 | 한 판을 끝낸 사람이 바로 한 판을 더 한다. 빌드와 밸런스를 빠르게 돌려 볼 시험대가 생긴다 |
| **4. 세 형태** | 지팡이와 활. 형태마다 9개 기술과 트리 전체 | 세 형태가 서로 다른 게임처럼 느껴진다. 형태마다 원형이 6개 이상 성립한다 |
| **5. 공개** | 스토어 페이지, 데모(프롤로그 + 1장 + 농성 맛보기), 넥스트 페스트 | 찜 목록과 데모 반응으로 방향을 확인한다 |
| **6. 캠페인 전체** | 3~5장, 남은 적과 보스, 장의 사건, 부형태, 일러스트와 결말 | 캠페인을 처음부터 끝까지. 세 형태로 |
| **7. 깊이** | 서약, 다시 깨어남, 시설 특화 전부, 성물과 룬 전부, 순위표 | 형태당 원형 12개 이상이 표준 난이도를 클리어한다 |
| **8. 다듬기와 출시** | 밸런스, UI, 사운드, 현지화, Steam Deck, 업적 | 출시 |

**농성을 캠페인 후반보다 먼저 만드는 이유:** 농성은 모든 시스템을 한 시간 안에 돌린다. 조합이 재미있는지, 숫자가 맞는지를 캠페인 8시간을 돌리지 않고도 확인할 수 있다. 캠페인 3~5장은 그 위에 얹는 손으로 짠 콘텐츠다.

### 18.3 규모

이 범위는 1인 기준으로 여러 해가 걸리는 일이다. 어림으로 2~3년이다. 그래서 위 순서의 각 단계가 그 자체로 내놓을 수 있는 물건이 되게 했다. 3단계가 끝나면 농성만으로도 얼리 액세스가 가능하고, 5단계에서 데모가 나온다.

### 18.4 넣지 않는 것

기간에 제한이 없어도 넣지 않는 것이 있다. 기둥에 기여하지 않기 때문이다.

| 넣지 않는 것 | 이유 |
|---|---|
| 곶에서의 전투 | "곶은 탐욕, 성벽은 공포"의 리듬이 무너진다 |
| 병사 고용과 지휘 | 왕이 직접 싸운다는 기둥과 부딪힌다 |
| 협동 플레이 | 한 사람이 성벽과 곶에 동시에 있을 수 없다는 것이 이 게임의 긴장이다. 둘이 나눠 맡으면 그 줄다리기가 사라진다 |
| 캠페인 중 형태 변경 | 선택의 무게가 사라진다. 농성과 다시 깨어남이 그 자리를 맡는다 |
| 영구 수치 강화형 메타 (농성) | 실력이 아니라 누적 시간이 이기게 된다 |
| 자유 건설 | 슬롯 제한이 선택을 만든다 |

## 19. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| **끝나지 않는 개발** | 기한이 없으면 범위가 계속 자란다 | 기둥 다섯 개에 기여하지 않는 것은 넣지 않는다. 단계마다 넘어가는 기준을 지킨다. 단계 사이에서만 범위를 다시 본다 |
| 탑다운에서 절벽 등반의 가독성 | 핵심 전투가 읽히지 않는다 | 프로토타입 1순위 검증. 계단식 절벽, 단별 색, 고정 카메라 |
| 채굴과 액션, 게임 두 개를 만드는 범위 | 어느 쪽도 깊어지지 못한다 | 곶에는 전투 없음. 무기와 채굴 도구 통일. 기술의 채굴 효과는 범위 판정 재사용 |
| 조합의 깊이가 복잡함으로만 느껴진다 | 신규 플레이어 이탈 | 장마다 한 층씩 공개. 무료 재배치. 가상 투자와 태그 검색. 농성에서 짧게 여러 번 시험 |
| 조합 수에 비해 검증이 모자라다 | 망가진 조합, 죽은 노드 | 태그 기반 데이터 설계. 농성 모드를 밸런스 시험대로 쓴다. 자동 시뮬레이션으로 극단값을 찾는다 |
| 전부 영구 누적이라 눈덩이가 구른다 | 잘하는 플레이어는 후반이 쉬워지고, 밀린 플레이어는 점점 더 밀린다 | 끝이 있는 자원, 장별 상한, 장마다 늘어나는 적의 경로, 함락 시 '결의' |
| 유한한 자원과 영구 투자 | 잘못 쓴 플레이어가 막힌다 | 되돌리기(전액 환급), 함락 시 되감기와 '결의', 난이도는 언제든 변경 |
| 왕 강화가 필수 선택이 된다 | 초반 빌드가 모두 같아진다 | 시뮬레이션에서 이미 보인다([밸런스 시트](./04_balance.md)). 왕 강화의 복리를 낮추거나 초반 비용을 조정한다 |
| 같은 성에서 다섯 장 | 전장이 단조로워진다 | 장마다 경로·슬롯·상처가 바뀐다. 장의 사건. 하늘과 날씨, 새 적 |
| 두 모드의 밸런스 | 한 모드에 맞춘 수치가 다른 모드를 망친다 | 같은 시스템, 다른 규칙 데이터. 능력치는 공유하고 곡선만 모드별로 둔다 |
| 트인 땅이라 탐사의 긴장이 약해진다 | 채굴이 단순 수거가 된다 | 해무로 시야를 가리고, 암반으로 길을 막고, 밀물로 시간을 조인다. 땅마다 캐는 방식을 다르게 한다 |
| 후반의 긴 귀환 동선 | 걷는 시간이 지루해진다 | 닦인 길, 옛 길, 광차 선로, 다리 강화 |
| 에셋 팩을 쓴 티 | 흔한 에셋을 그대로 쓴 게임으로 보인다 | 한 계열로 통일, 색 재지정, 공통 조명과 후처리, 고유한 UI와 일러스트 |
| AI 생성물에 대한 반응 | 상점 페이지에 공개 표시된다. 일부 구매자가 꺼린다 | 숨기지 않고 범위를 정확히 밝힌다(일러스트·아이콘). 캡슐과 키 아트는 직접 손질한다 |
| 벤치마크와의 유사성 | "돔 키퍼 3D"로만 보인다 | 직접 전투, 추락, 조합 깊이, 이야기 캠페인을 상점 페이지 전면에 |
