## 1. 게임 개요

### 1.1 한 줄 소개

**성 아래로 파 내려가 부서진 무기를 깨우고, 종이 울리면 성벽으로 돌아와 절벽을 기어오르는 군세를 직접 베어 떨어뜨리는 3D 탑다운 채굴·방어 액션.**

### 1.2 기본 정보

| 항목 | 내용 |
|---|---|
| 제목 | LOST REGALIA (가제) |
| 장르 | 채굴 × 거점 방어 × 액션 (챕터제 로그라이트 캠페인) |
| 시점 | 3D 탑다운, 고정 고각 카메라 |
| 플랫폼 | PC (Steam), Steam Deck 대응 |
| 인원 | 1인 |
| 벤치마크 | Dome Keeper (핵심 루프) |
| 플레이타임 | 캠페인 첫 클리어 7~9시간 (장당 45~60분 × 5장 + 재도전), 형태 3종 반복 시 20시간 이상 |
| 타깃 | 돔 키퍼류의 '채굴과 방어 사이의 긴장'을 좋아하고, 빌드 연구에 시간을 쓰는 플레이어 |
| 언어 | 한국어·영어 (출시 시점), 일본어·중국어 간체 (검토) |
| 가격 | 미정. 돔 키퍼와 같은 가격대를 출발점으로 검토 |

### 1.3 설계 기둥

모든 기능은 아래 네 문장 중 하나 이상에 기여해야 한다. 그렇지 않으면 뺀다.

| # | 기둥 | 뜻 |
|---|---|---|
| 1 | **탐욕과 귀환** | "하나만 더 캐고"와 종소리 사이의 줄다리기가 게임의 심장이다. |
| 2 | **왕이 직접 싸운다** | 포탑을 조작하는 것이 아니라, 플레이어의 손이 곧 방어선이다. |
| 3 | **깨어나는 무기** | 무기는 하나다. 그러나 깨우는 순서와 조합에 따라 전혀 다른 무기가 된다. |
| 4 | **성은 좁아지고, 왕은 강해진다** | 장마다 성벽을 하나 잃고 힘을 하나 얻는다. 이 두 곡선이 엇갈리며 캠페인을 끌고 간다. |

### 1.4 차별점

- **절벽이라는 전장.** 적은 걸어오지 않고 기어오른다. 높이 올라온 적일수록 떨어뜨렸을 때 이득이 크다([12.3 추락](#123-추락--이-게임만의-전투-규칙)).
- **무기 하나로 캐고 싸운다.** 채굴 도구와 전투 무기가 같다. 전투 빌드가 곧 채굴 빌드다.
- **여섯 겹의 조합.** 형태 → 기술 → 변형 → 인장 → 룬 → 진명·공명. 층마다 선택이 다음 층의 선택지를 바꾼다.
- **짧고 완결된 이야기.** 기억 하나가 스킬 트리의 한 단계를 연다. 이야기 보상과 성장 보상이 같은 순간에 온다.

## 2. 벤치마크 — 돔 키퍼에서 가져오는 것과 바꾸는 것

돔 키퍼의 재미는 **"안전하지만 가난한 지상"과 "풍요롭지만 먼 지하" 사이를 오가는 시간 관리**에 있다. 이 구조는 그대로 가져온다. 바꾸는 것은 방어의 방식과 성장의 깊이다.

| 돔 키퍼 | 본작 | 바꾸는 이유 |
|---|---|---|
| 돔 (방어 거점) | 절벽성의 성벽 | 설정. 패배 조건은 동일하게 '거점 내구도 0' |
| 2D 횡스크롤 지하 채굴 | 3D 탑다운 타일 채굴 ('심층') | 지상과 같은 시점·조작으로 통일 |
| 돔에 달린 무기를 조작 | 왕이 레갈리아를 들고 직접 전투 | 액션의 손맛, 빌드가 화면에 드러남 |
| 굴착기와 돔 무기가 별개 | 레갈리아 하나로 채굴과 전투 | 강화 선택의 무게를 키움 |
| 자원 3종 (철·물·코발트) | 성광석·흑철·룬 수정 (+ 적이 떨어뜨리는 마정) | 용도를 각성·성·조합으로 분리 |
| 가젯 (택1) | 성물 (택1) + 룬 | 조합 층 추가 |
| 유물을 지상으로 가져오면 승리 | 대파편을 가져오면 총공세 → 보스 → 장 클리어 | 플레이어가 클라이맥스 시점을 정하는 구조 유지 |
| 런 단위 로그라이크 | 장 단위로 다시 시작하되, 무기 각성은 영구 | 깊은 스킬 트리를 캠페인 내내 키우게 함 |
| 키퍼는 죽지 않는다 | 왕은 쓰러지지만 죽지 않는다 | 패배 조건을 '성' 하나로 유지 |
| 지하에는 적이 없다 | 동일 | "지하는 탐욕, 지상은 공포"의 리듬 보존 |

**버리는 것:** 지하 전투, 다수 유닛 지휘, 건설 배치 퍼즐. 초점을 흐린다.

## 3. 핵심 루프

### 3.1 한 주기 (약 2~3분)

```
        ┌───────────────  고요  ───────────────┐
        │   ① 내려간다 → ② 캔다 → ③ 나른다      │
        │      깊을수록 많이 얻고, 멀어진다       │
        └──────────────────┬──────────────────┘
                           │  종이 울린다 (경보)
                           ▼
        ┌───────────────  습격  ───────────────┐
        │   ④ 돌아온다 → ⑤ 성벽에서 싸운다       │
        └──────────────────┬──────────────────┘
                           ▼
              ⑥ 깨운다 · 짓는다 · 고친다
           (레갈리아 각성 / 방어 시설 / 성벽 수리)
                           │
                           └────► 다시 ①
```

### 3.2 세 가지 시간 단위

| 단위 | 길이 | 내용 | 플레이어의 질문 |
|---|---|---|---|
| **주기** | 2~3분 | 고요 → 습격 → 강화 | "지금 올라갈까, 하나만 더 캘까?" |
| **장** | 45~60분 | 주기 10~12회 → 대파편 회수 → 총공세 → 보스 | "무기에 쓸까, 성에 쓸까? 대파편은 언제 올릴까?" |
| **캠페인** | 7~9시간 | 5장. 각성은 누적되고 성벽은 줄어든다 | "이 무기를 어떤 무기로 만들 것인가?" |

### 3.3 한 장의 흐름 (1장 예시)

| 시점 | 벌어지는 일 |
|---|---|
| 0분 | 새 성벽 도착. 시설 없음, 성벽 내구도 가득. 수직갱으로 내려간다. |
| 0~10분 | 심층 1층. 흙과 연암을 파며 성광석을 모은다. 습격은 약하다. 첫 시설(종탑 또는 발리스타)을 짓는다. |
| 10~25분 | 2층 진입. 흑철이 나오기 시작하고 귀환이 길어진다. 봉인실에서 성물을 고른다. 습격에 석궁수와 사다리조가 섞인다. |
| 25~40분 | 3층. 기억의 방을 찾는다. **대파편을 들어 올릴지 결정한다.** 올리는 순간 총공세가 시작된다. 준비가 덜 됐다면 더 캔다. 그러나 습격은 계속 강해진다. |
| 40~50분 | 총공세와 보스. 승리하면 성벽이 무너지고 다음 장으로 물러선다. |

## 4. 세계와 이야기

전문은 [시나리오 문서](./01_scenario.md)에 있다. 기획에 필요한 요점만 옮긴다.

- **상황:** 절벽성 그레이홀트. 왕이 기억을 잃고 깨어난다. 손에는 형태 없는 왕가의 증표 '레갈리아'. 절벽 아래에는 마계와 손잡은 옛 적수 발카르의 군세.
- **레갈리아가 약한 이유:** 발카르의 저주를 대신 맞고 부서졌다. 힘과 기억은 파편이 되어 성 아래로 가라앉았다. → **심층 탐사의 이유.**
- **기억 다섯 개:** 장마다 대파편 하나를 되찾고, 그때마다 기억과 각성 단계가 함께 열린다. → **성장의 박자.**
- **진실:** 10년 전 왕은 발카르를 '살려 보낸' 것이 아니라 "벨 가치도 없다"며 버려두었다. 침공은 그 한마디의 값이다.
- **성벽의 후퇴:** 장마다 성벽 하나가 무너진다. → **장마다 새 전장, 시설 초기화.**
- **결말 둘:** 벤다(계약 완결, 마계는 다시 온다) / 손을 내민다(계약을 태우고 레갈리아를 잃는다 — 진결말).

## 5. 게임 공간 — 성벽과 심층

### 5.1 전체 구조

```
 [개념 단면도 — 실제 시점은 탑다운]

          왕좌 (재기 지점)
   ────────┬───────────────┐
    안뜰    │  성벽 (전투)   │╲   ← 적: 절벽면 등반, 성문길, 공중
   ───┬────┴───────────────┘ ╲
      │ 수직갱 (계단·승강기)    ╲  절벽
      ▼                         ╲
   ┌────────────────┐            ╲_____ 절벽 아래 (적 진영 · 균열)
   │ 심층 1층        │
   ├────────────────┤   깊을수록
   │ 심층 2층        │   자원↑  암반 강도↑  귀환 시간↑
   ├────────────────┤
   │ 심층 3층 ◆대파편 │
   └────────────────┘
```

### 5.2 지상 — 성벽

카메라는 **절벽 바깥 허공에서 성을 바라보는 고각**(약 55°)이다. 화면 위쪽이 성 안, 가운데가 성벽 위 통로, 아래쪽이 절벽면이다. 적은 화면 아래에서 위로 올라온다.

```
 ┌────────────────────── 화면 ──────────────────────┐
 │   왕좌(재기)        안뜰          [수직갱 입구]     │ ← 성 안쪽
 │ ═══╦═══════════╦═══════════╦═══════════╦═══════ │
 │    ║  구역 1   ║   구역 2   ║   구역 3   ║ 성문탑 │ ← 성벽 위 통로 (왕의 전장)
 │ ═══╩═══════════╩═══════════╩═══════════╩═══╗    │
 │   ▲ ▲ ▲         ▲ ▲ ▲ ▲         ▲ ▲        ║ ▲  │ ← 절벽면 (계단식 암반)
 │   좌 절벽면      중앙 절벽면      바위턱      ║성문길│
 │   ▲   ▲           ▲   ▲                    ║ ▲  │
 │ ~~~~~~~~~~ 절벽 아래: 적 진영 · 균열 ~~~~~~~~~~~~ │
 └──────────────────────────────────────────────────┘
          공중 경로: 화면 좌우 가장자리에서 진입
```

| 요소 | 규칙 |
|---|---|
| 성벽 위 통로 | 좌우로 긴 띠. 끝에서 끝까지 달려 약 7초. 양쪽이 동시에 뚫리면 한쪽을 포기해야 한다. |
| 구역 | 3~4개. 구역마다 시설 슬롯이 있다. |
| 성벽 내구도 | 성 전체에 하나. 0이 되면 함락(패배). |
| 접근 경로 | ① 좌 절벽면 ② 중앙 절벽면 ③ 성문길(중장갑·공성) ④ 공중 |
| 절벽면 | 계단식 암반 3~4단. 적의 높이가 한눈에 읽혀야 한다. 바위턱은 원거리 적이 자리 잡는 곳이다. |
| 적이 성벽에 닿으면 | 성벽 내구도와 시설을 공격한다. 일부는 왕을 노린다. |

### 5.3 지하 — 심층

- 탑다운 타일 채굴. 상세는 [11장](#11-심층-탐사).
- **조명:** 어둡다. 레갈리아가 유일한 광원이며, 빛의 반경이 곧 시야다.
- **지상 감시:** 지하에 있는 동안 화면 위에 '성벽 띠'(성벽 축소도)가 뜬다. 공격받는 구역이 붉게 깜박인다.

### 5.4 수직갱

지상과 심층을 잇는 유일한 통로. **귀환 시간이 긴장의 원천**이므로 순간이동은 기본으로 주지 않는다.

| 이동 | 시간 |
|---|---|
| 수직갱 입구 ↔ 1층 | 약 5초 |
| 층 하나 추가 | +6초 |
| 승강기 시설 | 층간 이동 시간 절반, 자원 자동 인양 |

## 6. 플레이어 — 왕

### 6.1 조작

| 행동 | 키보드·마우스 | 게임패드 |
|---|---|---|
| 이동 | WASD | 왼쪽 스틱 |
| 조준 | 마우스 | 오른쪽 스틱 |
| 기본 공격 / 채굴 | 좌클릭 | RT |
| 고유 동작 (패링·룬 설치·집중) | 우클릭 | LT |
| 기술 1·2·3 | Q · E · R | LB · RB · Y |
| 궁극기 | F | LB+RB |
| 대시 | Space | A |
| 상호작용 | C | X |
| 운반물 내려놓기 | G | B |
| 각성 트리 / 지도 | Tab / M | View / 십자키 |

- 키 재설정 지원. 게임패드만으로 모든 조작이 가능해야 한다.
- 게임패드에는 조준 보조를 제공한다.

### 6.2 왕의 상태

| 항목 | 규칙 |
|---|---|
| 체력 | 있다. 성벽 위에서 서서히 회복. |
| **쓰러짐** | 체력 0 → 왕좌에서 6초 뒤 재기. 그동안 성벽은 무방비다. 죽음은 없다. |
| 대시 | 짧은 무적. 재사용 대기 약 2초. |
| 운반 | 자원은 '빛의 실'에 꿰여 왕 뒤를 따라온다. 많이 끌수록 느려진다. |
| 지하에서 | 전투가 없다. 위험은 환경뿐이다. |

## 7. 레갈리아 — 세 가지 형태

프롤로그에서 하나를 고른다. 캠페인 중에는 바꿀 수 없다. 세 형태는 **적을 어느 높이에서 처리하는가**로 갈린다.

| | 검 | 지팡이 | 활 |
|---|---|---|---|
| 교전 높이 | 성벽 가장자리 (근거리) | 절벽면 전체 (중거리) | 절벽 아래~중턱 (원거리) |
| 지상에서의 방식 | 올라온 적을 베고, 패링하고, 밀어 떨어뜨린다 | 지대·설치·소환으로 절벽을 요새화한다 | 올라오기 전에 솎아 낸다. 약점과 관통 |
| 강점 | 순간 화력, 추락 유발 | 넓은 범위, 왕이 자리를 비워도 버팀 | 안전거리, 후방의 위험한 적 제거 |
| 약점 | 왕이 늘 위험하다. 공중·후방에 약함 | 느리다. 준비가 필요하다 | 성벽에 붙은 적에게 약함 |
| 고유 동작 | **패링** — 맞는 순간 받아치면 반격 | **룬 설치** — 기술을 그 자리에 심는다 | **집중** — 느려지는 대신 약점이 보인다 |
| 채굴 특성 | 전방 3타일을 넓게, 빠르게 | 충전 후 원격 범위 폭파 | 직선으로 멀리 관통. 먼 광맥을 쏘아 떨어뜨림 |
| 심층에서의 방식 | 넓은 방을 빠르게 판다 | 한 번에 크게 무너뜨린다 | 좁고 긴 굴로 깊이 찌른다 |
| 권장 숙련도 | 중 | 상 | 하~중 |
| 왕의 모습 | 선두에 서는 왕 | 다스리는 왕 | 내다보는 왕 |

**공통 기본기:** 기본 공격 / 강공격(충전) / 고유 동작 / 대시.

## 8. 각성 시스템 — 스킬 트리와 조합

이 게임의 장기 재미를 책임지는 장이다.

### 8.1 설계 목표

1. **한 무기, 여러 플레이.** 같은 검이라도 빌드에 따라 손의 움직임이 달라져야 한다.
2. **선택에는 대가.** 한 캠페인에서 트리의 약 55%만 깨울 수 있다. 전부 가질 수 없다.
3. **실험은 공짜.** 고요 중 왕좌에서 무료로 재배치한다. 고민은 시키되 벌은 주지 않는다.
4. **층층이 쌓이는 조합.** 한 층의 선택이 다음 층의 가치를 바꾼다.
5. **빌드가 시간 배분을 바꾼다.** 직접 싸우는 빌드는 성벽에 묶이고, 설치·소환 빌드는 지하에 오래 머문다. 빌드 선택이 곧 '탐욕과 귀환'의 답이다.

### 8.2 조합의 여섯 층

| 층 | 무엇을 고르나 | 선택 폭 | 얻는 곳 |
|---|---|---|---|
| ① **형태** | 검 / 지팡이 / 활 | 3 중 1 | 프롤로그 |
| ② **기술** | 능동 기술 9개 중 3개 장착 + 궁극기 3개 중 1개 | 가지 3개에 걸쳐 분포 | 각성 트리 |
| ③ **변형** | 기술마다 2단 분기(A/B) → 기술 하나당 최종형 4종 | 기술 9 × 4형 | 각성 트리 |
| ④ **인장** | 기술 슬롯마다 속성 하나 (5종) | 슬롯당 5 중 1 | 대파편·보스 |
| ⑤ **룬** | 기술 소켓 1~3칸에 끼워 동작을 바꿈 (약 20종) | 소켓당 1 | 심층 봉인실 |
| ⑥ **진명·공명·이형** | 규칙을 바꾸는 진명(최대 3), 태그 공명, 부형태 | — | 트리·수집·3장 클리어 |

### 8.3 각성 트리의 구조

화면 은유는 **레갈리아 안에 잠든 별자리**다. 노드는 별, 가지는 성좌. 깨울 때마다 별이 켜진다.

```
 단계      〈가지 A〉          〈가지 B〉          〈가지 C〉

 5        ●─[궁극]─●         ●─[궁극]─●         ●─[궁극]─●
 4        ●   ◆   ●────✦────●   ◆   ●────✦────●   ◆   ●
 3        ●─[진명]─●         ●─[진명]─●         ●─[진명]─●
 2        ●   ◆   ●────✦────●   ◆   ●────✦────●   ◆   ●
 1        ●───◆───●         ●───◆───●         ●───◆───●
               ╲                 │                 ╱
                ╲───────  [ 줄기 · 공용 ]  ───────╱

 ◆ 능동 기술   ● 수동·변형 분기   ✦ 교차 노드 (양쪽 가지에 투자해야 열림)
```

**형태당 노드 69개**

| 구분 | 수 | 설명 |
|---|---|---|
| 줄기 | 6 | 공용 기본기. 채굴 위력, 빛의 반경, 기본 공격 강화 |
| 가지 3개 × 19 | 57 | 가지 하나 = 기술 3 + 변형 분기 6 + 수동 8 + 진명 1 + 궁극 1 |
| 교차 노드 | 6 | 인접한 두 가지에 각 5노드 이상 투자하면 열리는 혼합 효과 |

**노드의 종류**

| 종류 | 역할 |
|---|---|
| 기술 | 새 능동 기술을 연다. 장착 칸은 3개뿐이다. |
| 변형 분기 | A와 B 중 하나만 고른다. 기술의 동작이 달라진다. |
| 수동 | 조건부 효과 중심. 단순 수치 증가는 최소화한다. |
| 교차 | 두 가지의 성격을 섞는다. 혼합 빌드의 보상. |
| **진명** | 규칙을 바꾼다. 큰 이득과 뚜렷한 대가가 함께 온다. |
| 궁극 | 가지의 완성형 기술. 하나만 장착한다. |

**단계의 개방 — 이야기와 맞물린다**

| 시점 | 열리는 것 |
|---|---|
| 프롤로그 | 1단계 |
| 1장 대파편 | 2단계 · 인장 택1 (화염/서리/뇌전) · 룬 소켓 |
| 2장 대파편 | 3단계(진명) · 진명 슬롯 1 · 인장 택1 |
| 3장 대파편 | 4단계 · 성광 인장 |
| 3장 클리어 | 공허 인장 제안 · 이형 각성 |
| 4장 대파편 | 5단계(궁극) · 진명 슬롯 2 · 남은 인장 |
| 5장 대파편 | **진명 해방** — 진명 슬롯 3 · 궁극기 진화 |

대파편은 **회수한 순간** 효력이 생긴다. 새 단계의 힘을 그 장의 보스전에서 바로 쓴다.
교차 노드는 단계와 무관하게 양쪽 가지의 투자량만으로 열린다.

### 8.4 형태별 가지와 기술

모든 능동 기술은 **지하에서 채굴 효과**를 겸한다. (예: 검기는 직선 5타일을 판다.)

#### 검

| 가지 | 성격 | 기술 | 진명 |
|---|---|---|---|
| **섬광** | 속도·연격·검기 | 질풍베기(돌진 베기) · 검기(절벽 아래로 날아가는 참격) · 잔상(분신이 직전 공격을 반복) | **멈추지 않는 칼** — 연속 처치마다 공격 속도 누적. 3초간 처치가 없으면 전부 사라지고 잠시 둔화 |
| **철벽** | 패링·반격·수호 | 왕의 방패(패링 범위 확대, 성공 시 반격파) · 도발의 함성(적이 성벽 대신 왕을 노림) · 불퇴(짧은 시간 밀려나지 않고 받은 피해를 되돌림) | **한 걸음도** — 성벽이 받는 피해의 40%를 왕이 대신 받는다. 왕의 체력 재생 대폭 증가 |
| **파멸** | 충전·범위·추락 | 내려찍기(범위 강타, 등반 중인 적을 떨어뜨림) · 대지 가르기(절벽면을 타고 내려가는 균열) · 처형(약해진 적 즉사, 처치 시 재사용) | **성을 부수는 검** — 모든 공격이 충전 공격이 된다. 피해·범위 대폭 증가, 연타 불가 |

#### 지팡이

| 가지 | 성격 | 기술 | 진명 |
|---|---|---|---|
| **파동** | 광역·지대 | 장막(절벽면을 가로지르는 띠 지대) · 유성(지연 후 광역 낙하) · 밀물(왕 중심으로 밀어냄, 추락 유발) | **마르지 않는 샘** — 지대가 사라지지 않는다. 동시에 3개까지만 유지 |
| **소환** | 석상·정령 | 수호 석상(성벽에 세우는 근접 수호자) · 등불 정령(지상에서는 적 약화, 지하에서는 자원 운반) · 돌의 군세(잠시 낙석 골렘 다수) | **섬기는 자들의 왕** — 소환수 수 2배, 지속 무한. 왕의 직접 피해 60% 감소 |
| **결계** | 설치·속박·증폭 | 속박의 문양(등반을 멈추는 설치 덫) · 증폭진(진 안의 시설·소환수·왕 강화) · 역류(적 투사체 반사, 적 강화 해제) | **그어진 선** — 성벽 가장자리에 영구 결계선. 넘는 적에게 큰 피해. 발동할 때마다 왕의 체력 소모 |

#### 활

| 가지 | 성격 | 기술 | 진명 |
|---|---|---|---|
| **저격** | 약점·관통·충전 | 꿰뚫는 화살(직선 관통) · 약점 사격(충전, 약점 명중 시 치명) · 별 떨구기(절벽 아래 후방까지 닿는 초장거리 곡사) | **한 발** — 화살을 한 발만 장전한다. 피해 대폭 증가, 관통 무한, 재장전 길다 |
| **난사** | 다중·속사·도탄 | 부채살(부채꼴 다중 사격) · 화살비(지대) · 도탄(적 사이를 튕김) | **빈 화살통** — 조준이 자동이 된다. 공격 속도 2배, 치명타 없음 |
| **사냥** | 덫·표식·매 | 사냥감 표식(표식 대상에게 시설과 소환수가 집중) · 올가미 덫(절벽면에 설치) · 사냥매(지상에서는 자율 공격, 지하에서는 광맥 탐지) | **몰이사냥** — 표식 대상을 처치하면 표식이 옮겨 가며 피해가 누적. 표식 없는 적에게는 피해 감소 |

#### 변형 분기의 예 — 검기

| 분기 | A | B |
|---|---|---|
| 1차 | **관통** — 약하지만 절벽 아래까지 닿는다 | **폭발** — 가까이서 터지며 밀어낸다 |
| 2차 | **삼연** — 세 갈래로 나간다 | **회귀** — 되돌아오며 한 번 더 벤다 |

같은 검기가 '관통·삼연'이면 원거리 견제기, '폭발·회귀'면 성벽 가장자리의 추락 유발기가 된다.

### 8.5 인장 — 속성과 반응

기술 슬롯마다 인장 하나를 찍는다. 인장은 그 기술의 피해 속성과 상태이상을 정한다.

| 인장 | 상태이상 | 효과 | 잘 맞는 상황 |
|---|---|---|---|
| **화염** | 점화 | 지속 피해. 처치 시 인접 적에게 번진다 | 오래 기어오르는 무리 |
| **서리** | 냉기 → 빙결 | 둔화 누적, 5중첩 시 2초 정지. 등반 중 빙결되면 떨어뜨리기 쉽다 | 추락 빌드, 시간 벌기 |
| **뇌전** | 감전 | 피해 일부가 가까운 적 둘에게 연쇄 | 밀집한 무리 |
| **성광** | 낙인 | 마계 적에게 추가 피해. 낙인 대상 처치 시 성벽 소량 회복 | 장기전, 수호 빌드 |
| **공허** | 침식 | 적 최대 체력 비례 피해. **쓸 때마다 부채가 쌓인다** | 보스·대형 적 |

**반응** — 서로 다른 두 상태이상이 한 적에게 겹치면 발동한다.

| | 서리 | 뇌전 | 성광 | 공허 |
|---|---|---|---|---|
| **화염** | **파열** — 빙결을 터뜨려 방어 감소와 범위 피해 | **폭뢰** — 범위 폭발, 밀어냄 | **정화의 불** — 점화가 번질 때 낙인도 함께 번진다 | **재** — 처치한 적이 다시 일어나지 못한다 |
| **서리** | — | **전도** — 빙결된 적을 지나는 연쇄는 약해지지 않는다 | **빙벽** — 빙결된 적이 잠시 벽이 되어 뒤따르는 등반을 막는다 | **정적** — 범위 안의 적 능력 봉쇄 |
| **뇌전** | | — | **천벌** — 낙인 대상에게 낙뢰 추가타 | **누전** — 연쇄가 침식을 함께 옮긴다 |
| **성광** | | | — | **일식** — 큰 단일 피해, 부채 일부 탕감 |

**부채** — 발카르와 같은 길

공허 인장은 3장에서 징수인을 쓰러뜨린 뒤 '제안'으로 온다. **받을지 말지는 플레이어가 정한다.**

| 부채 게이지 | 결과 |
|---|---|
| 33% | 다음 습격에 엘리트 '징수꾼'이 섞인다 |
| 66% | 성벽 최대 내구도 감소 |
| 100% | **징수** — 성벽에 즉시 큰 피해, 게이지 초기화 |

- 상환 수단: '일식' 반응, 성광석 봉헌.
- 의도: 가장 강한 힘에 이자를 붙인다. 플레이어가 발카르의 선택을 직접 저울질하게 한다.

### 8.6 룬 — 기술의 동작을 바꾼다

심층의 봉인실과 보스에게서 얻는다. 기술 소켓에 끼운다. 소켓은 기술당 1칸에서 시작해 트리에서 3칸까지 늘린다.

| 룬 | 효과 | 태그 |
|---|---|---|
| 분열 | 투사체·충격파가 둘로 갈라진다 | 연쇄 |
| 관통 | 적을 뚫고 지나간다 | — |
| 잔류 | 기술이 지나간 자리에 지대를 남긴다 | 지대 |
| **설치** | 기술을 성벽에 거치한다. 주기적으로 자동 발동, 위력은 줄어든다 | 설치 |
| 반향 | 일정 확률로 한 번 더 발동 | 연쇄 |
| 응축 | 범위가 줄고 피해가 는다 | 처형 |
| 확산 | 범위가 늘고 피해가 준다 | 지대 |
| 지연 | 늦게 터지고 더 세게 터진다 | 충전 |
| 밀침 | 밀어내는 힘 증가 | 추락 |
| 흡수 | 처치 시 왕 또는 성벽 소량 회복 | 수호 |
| 표적 | 맞은 적에게 표식을 남긴다 | 표식 |
| 굴착 | 지하에서 이 기술의 채굴 범위·위력 증가 | 탐사 |

**'설치' 룬은 빌드의 갈림길이다.** 어떤 기술이든 자동 방어 수단으로 바꿔, 왕이 지하에 더 오래 머물 수 있게 한다.

### 8.7 공명 — 태그를 모으면 생기는 힘

노드·룬·성물·시설에는 모두 태그가 붙어 있다. 같은 태그를 3 / 6 / 9개 모으면 공명이 켜진다.

| 태그 | 3개 | 6개 | 9개 |
|---|---|---|---|
| 연쇄 | 연쇄 대상 +1 | 연쇄할 때마다 피해 소폭 증가 | 연쇄가 같은 적을 다시 칠 수 있다 |
| 설치 | 설치물 지속 증가 | 설치물이 왕의 인장을 이어받는다 | 왕이 지하에 있는 동안 설치물 강화 |
| 추락 | 낙하 피해 증가 | 떨어진 적이 아래 적을 함께 떨어뜨린다 | 추락사한 적이 자원을 떨어뜨린다 |
| 수호 | 성벽 수리 효율 증가 | 성벽이 맞으면 가시 반격 | 성벽 내구도가 낮을수록 왕이 강해진다 |
| 표식 | 표식 대상 피해 증가 | 시설이 표식 대상을 우선한다 | 표식 대상 처치 시 주변에 표식 전파 |
| 지대 | 지대 범위 증가 | 겹친 지대가 서로 강화 | 지대 안의 적은 등반 속도 대폭 감소 |

1.0 목표 태그 수: 8~10개 (위 6개 + 소환·처형·충전·탐사).

### 8.8 이형 각성 — 두 번째 형태의 그림자

3장을 넘기면 레갈리아가 **고르지 않은 형태 하나의 가지 하나**를 부형태로 받아들인다. 부형태 기술은 한 칸에만 장착한다.

- 예: 검(주) + 활의 '사냥' → 덫을 깔고 표식을 찍은 뒤 패링으로 마무리하는 사냥꾼 왕.
- 예: 활(주) + 지팡이의 '결계' → 절벽면에 증폭진을 깔고 그 위로 화살비.

### 8.9 빌드 예시

| 빌드 | 구성 | 플레이 | 약점 |
|---|---|---|---|
| **빙결 연쇄 궁수** | 활·난사(도탄) + 서리·뇌전 인장 + 분열·반향 룬 + 피뢰탑 | 얼리고, 얼어붙은 무리 사이로 번개를 튕긴다. '전도' 반응이 핵심 | 대형 단일 적, 보스 |
| **가시 성벽 검왕** | 검·철벽 + 진명 '한 걸음도' + 성광 인장 + 수호 공명 9 | 성벽 대신 왕이 맞고, 맞을수록 강해진다. 성벽을 일부러 낮게 유지하는 줄타기 | 공중, 후방 주술사 |
| **부채의 마도왕** | 지팡이·파동 + 공허 인장 다수 + 성광 '일식'으로 상환 | 가장 높은 화력. 부채 게이지를 60% 근처에서 굴린다 | 실수 한 번이 '징수'로 이어진다 |
| **지하의 사냥꾼** | 활·사냥(덫·매) + 설치 룬 + 지팡이 '결계' 부형태 + 운반 석상 | 성벽은 덫과 설치물에 맡기고 지하에 가장 오래 머문다. 자원으로 압도 | 설치물을 부수는 적, 왕을 노리는 암살자 |
| **추락 전문가** | 검·파멸(내려찍기) + 서리 인장 + 밀침 룬 + 낙석 장치 + 추락 공명 | 일부러 높이 올라오게 두었다가 한꺼번에 떨어뜨린다 | 타이밍 실수, 공중 |

### 8.10 조합의 규모와 밸런스 원칙

- 형태 하나에서 기술 3개 선택(84가지) × 변형(64) × 인장(125) = **약 67만 가지** 기술 구성. 룬·진명·공명·이형을 더하면 사실상 셀 수 없다.
- 그러나 목표는 숫자가 아니다. **형태당 뚜렷이 다른 플레이 원형 12~15개**가 성립하는 것이 목표다.
- 모든 효과는 데이터로 정의하고 태그로 상호작용시킨다. 개별 조합을 하드코딩하지 않는다.
- 진명은 반드시 대가를 갖는다. 대가 없는 진명은 수동 노드로 내린다.
- 수치 증가만 하는 노드는 전체의 30% 이하로 묶는다.

## 9. 성 — 방어 시설과 왕 강화

각성이 '영구히 쌓이는 축'이라면, 이 장은 **장마다 새로 짜는 축**이다. 장이 바뀌면 성벽도 시설도 왕 강화도 처음으로 돌아간다. 돔 키퍼의 한 판처럼, 매 장이 '빈손에서 요새까지'의 곡선을 갖는다.

### 9.1 성벽

| 항목 | 규칙 |
|---|---|
| 내구도 | 성 전체에 하나. 장 시작 시 가득 |
| 수리 | 흑철을 써서 고요 중에 수리. 습격 중에는 불가 |
| 강화 | 최대 내구도, 피해 경감 |

### 9.2 방어 시설

성벽당 슬롯은 5칸 안팎이다. 전부 지을 수 없다.

| 시설 | 효과 | 태그 |
|---|---|---|
| 종탑 | 경보를 더 일찍 울린다. 다음 습격의 구성을 미리 보여 준다 | — |
| 승강기 | 수직갱 이동 시간 절반, 자원 자동 인양 | 탐사 |
| 발리스타 | 느리고 강한 자동 사격. 표식 대상을 우선한다 | 표식 |
| 기름 솥 | 구역 아래로 쏟는다. 화염 인장이 닿으면 불타는 지대가 된다 | 지대 |
| 가시 난간 | 성벽 가장자리에 닿은 적에게 피해, 등반 지연 | 수호 |
| 피뢰탑 | 주기적 낙뢰. 뇌전 연쇄의 중계점이 된다 | 연쇄 |
| 성광 등대 | 공중 적을 늦추고 낙인을 찍는다 | — |
| 낙석 장치 | 수동 발동. 한 경로 전체에 추락 유발. 재장전에 흑철 소모 | 추락 |
| 수리 작업대 | 고요 중 성벽을 천천히 자동 수리 | 수호 |

시설은 왕의 빌드와 맞물려야 가치가 커진다. (예: 표식 빌드 + 발리스타, 뇌전 빌드 + 피뢰탑)

### 9.3 왕 강화

| 축 | 효과 | 단계 |
|---|---|---|
| 다리 | 이동 속도, 대시 횟수 | 4 |
| 등 | 운반량, 운반 중 속도 | 4 |
| 눈 | 빛의 반경, 광맥 탐지 | 4 |
| 심장 | 체력, 재기 시간 단축 | 4 |

채굴 위력은 왕 강화가 아니라 **레갈리아의 줄기 노드**에 있다. 무기가 강해져야 깊이 내려갈 수 있다.

```
                    성광석 · 흑철
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
   레갈리아 각성       성 (시설·수리)      왕 강화

```

- **초반:** 왕 강화(복리)에 쓰고 싶지만, 다음 습격을 못 막으면 의미가 없다.
- **중반:** 시설로 성벽을 안정시킬수록 지하에 오래 머문다.
- **후반:** 총공세 전에 각성과 수리 중 어디에 남은 자원을 쓸지 정한다.

## 11. 심층 탐사

### 11.1 생성

- 장마다 3~4층. 층 하나는 약 36×36 타일.
- 절차적 생성으로 암반과 광맥을 깔고, 손으로 만든 '방'(봉인실·기억의 방 등)을 끼워 넣는다.
- 대파편이 있는 기억의 방은 항상 최심층에 있다. 위치는 매번 다르다.

### 11.2 타일

| 타일 | 강도 | 비고 |

| 흙 | 1타 | 1층 대부분 |

| 기반암 | 파괴 불가 | 층의 뼈대, 길을 강제한다 |

### 11.3 구조물

| 구조물 | 내용 |
|---|---|
| **봉인실** | 성물 셋 중 하나를 고른다. 층당 0~1개 |
| **기억의 방** | 대파편. 들어 올리는 순간 총공세가 예고된다 |

### 11.4 위험 — 전투는 없다, 환경만 있다

| 위험 | 내용 | 이용법 |
|---|---|---|
| 가스 주머니 | 터지면 주변 타일과 왕에게 피해 | 일부러 터뜨려 넓게 판다 |
| 낙반 | 넓게 판 천장이 무너져 길을 막는다 | 기둥을 남기며 판다 |
| 침수 | 물이 차오르는 구역. 이동 속도 감소 | 물길을 다른 방으로 돌린다 |
| 마계 침식 (3장부터) | 타일이 서서히 번지며 광맥을 오염시킨다 | 성광 인장으로 정화하면 자원 추가 |

### 11.5 운반

- 캔 자원은 바닥에 떨어진다. 다가가면 '빛의 실'에 꿰여 왕을 따라온다.
- 많이 끌수록 느려진다. 무엇을 두고 갈지 고르는 것이 귀환 판단의 일부다.
- 수직갱에 닿으면 수령된다. 쓰러지거나 급히 버리면 그 자리에 남는다.

### 11.6 성물 (봉인실 택1)

1.0 목표는 약 15종. 대표 예:

| 성물 | 효과 |

| 길잡이 실타래 | 수직갱으로 즉시 귀환. 주기당 1회 |
| 운반 석상 | 떨어진 자원을 수직갱까지 스스로 나른다 |
| 메아리 종 | 지하에서 경보를 더 일찍 듣고, 성벽 상황을 본다 |

| 성광 화로 | 성광석을 태워 성벽을 수리한다 |

| 깨진 모래시계 | 고요가 길어지고, 그만큼 습격이 거세진다 |

## 12. 적과 습격

### 12.1 습격의 규칙

```
  고요 (약 100초)  →  경보: 종 (습격 15초 전)  →  습격 (40~90초, 전멸 시 종료)  →  고요 …
```

| 규칙 | 내용 |
|---|---|
| 왕이 지하에 있어도 | 습격은 시작된다. 시설만이 버틴다 |
| 빨리 끝낼수록 | 다음 고요가 빨리 시작된다. 전투 실력이 곧 채굴 시간이다 |
| 강도 | 습격마다 '위협 예산'이 늘고, 예산으로 적을 산다. 적마다 값이 다르다 |
| 엘리트 습격 | 5번째마다. 엘리트가 마정을 떨어뜨린다 |
| 총공세 | 대파편을 지상으로 올리면 시작. 보스가 온다 |

### 12.2 접근 경로

| 경로 | 오는 적 | 대응 |
|---|---|---|
| 좌·중앙 절벽면 | 등반하는 다수 | 세 형태 모두의 주 전장 |
| 바위턱 | 절벽 중턱에 자리 잡는 원거리 적 | 원거리 수단 또는 설치물 |
| 성문길 | 느리고 단단한 공성 병기 | 집중 화력, 낙석·기름 |
| 공중 | 시설을 노리는 비행체 | 성광 등대, 범위기 |

### 12.3 추락 — 이 게임만의 전투 규칙

- 등반 중인 적에게는 **붙잡기** 수치가 있다. 밀어내는 힘을 받으면 깎이고, 0이 되면 떨어진다.
- 낙하 피해는 **높이에 비례**한다. 떨어지는 적은 아래의 적과 부딪혀 함께 피해를 준다.
- 빙결·속박 상태의 적은 붙잡기가 크게 약해진다.

**높이의 딜레마:** 낮은 곳에서 잡으면 안전하지만 추락 이득이 없다. 성벽 턱밑까지 올라오게 두면 위험하지만, 떨어뜨릴 때 한 줄을 통째로 쓸어 낸다. 활은 전자, 검은 후자에 가깝고, 빌드에 따라 뒤집을 수 있다.

| | 심연의 손 | 5장 | 절벽에서 돋아나 시설을 붙잡아 봉쇄한다 | 근접 처치 |

**엘리트 수식어** (3장부터): 불타는 / 얼어붙은 / 보호막 / 압류하는(처치 전까지 가까운 시설 봉쇄).

### 12.5 보스

| 장 | 보스 | 전투 | 설계 의도 |
|---|---|---|---|
| 1 | **공성대장 그룸** | 성문길의 거대 공성추와 절벽면의 사다리 다발이 동시에 온다 | 두 경로 사이의 우선순위, 시설의 가치 |
| 2 | **타락기사 세라벨** | 성벽 위로 뛰어올라 왕과 일대일로 싸운다. 그동안 등반은 계속된다 | 왕 자신이 표적이 되는 전투. 회피와 패링 |

### 15.2 각성 트리 화면

- 별자리 형태. 깨운 별과 깨울 수 있는 별, 아직 닿지 않는 별이 한눈에 구분된다.
- **가상 투자:** 확정 전에 노드를 찍어 보고, 기술 설명과 공명 변화를 미리 본다.
- **태그 검색:** 태그를 누르면 그 태그가 붙은 노드·룬·시설이 전부 빛난다.
- **빌드 보관:** 구성을 3개까지 저장하고 불러온다.

### 15.3 온보딩

- 프롤로그 10분 안에 루프 한 바퀴(싸운다 → 내려간다 → 캔다 → 종이 울린다 → 돌아온다)를 겪게 한다.
- 시스템은 장마다 하나씩 연다([13장](#13-챕터-구성)). 조합의 여섯 층을 한꺼번에 보여 주지 않는다.

### 15.4 접근성

- 속성은 색만이 아니라 아이콘 모양으로도 구분.
- 화면 흔들림·섬광 강도 조절.
- 조준 보조, 기술 꾹 누르기/전환 선택.
- 자막 크기 조절, 종소리의 시각 대체 표시.

## 16. 아트와 오디오

### 16.1 아트

| 항목 | 방향 |
|---|---|
| 양식 | 양식화된 3D. 굵은 실루엣, 손그림 질감. 사실적 묘사보다 **탑다운에서의 가독성** |
| 색 | 성과 왕 — 차가운 청회색에 성광의 금빛 / 카르둔 군 — 잿빛과 녹슨 붉은색 / 마계 — 자홍과 검정 |
| 지상 | 넓고 춥고 높다. 바람, 안개, 깃발. 장이 지날수록 하늘이 붉어진다 |
| 지하 | 어둡고 조용하다. 광원은 레갈리아뿐. 장마다 다른 암석과 빛깔 |
| 레갈리아 | 각성할수록 모습이 변한다. 깨운 가지에 따라 무기의 생김새가 달라진다 |
| 성벽의 손상 | 내구도가 화면에서 보여야 한다. 금, 무너진 흉벽, 불 |

### 16.2 오디오

- **종소리가 이 게임의 소리다.** 경보, UI 효과음, 음악의 주제 선율이 모두 종에서 나온다.
- 고요: 낮게 깔리는 지하의 울림. 음악은 거의 없다.
- 습격: 타악 중심. 적이 높이 올라올수록 층이 쌓인다.
- 발카르의 목소리: 절벽 아래에서 울려 올라오는 공간감. 장이 지날수록 사람의 목소리에서 멀어진다.
- 5장: 종이 없다. 그 자리를 침묵과 레갈리아의 떨림이 채운다.

### 18.2 단계

기간은 **3~5인 소규모 팀을 가정한 추정**이다. 팀 구성이 정해지면 다시 잡는다.

| 단계 | 기간 (가정) | 산출물 | 통과 기준 |
|---|---|---|---|
| **0. 종이 설계** | 1개월 | 수치 시뮬레이션, 트리 초안 | 주기당 자원과 비용 곡선이 표로 성립한다 |
| **1. 프로토타입** | 2~3개월 | 검 하나, 성벽 하나, 심층 한 종, 적 4종. 회색 상자 | **"하나만 더"와 종소리의 긴장이 3D 탑다운에서 성립하는가.** 아니면 여기서 고친다 |
| **2. 버티컬 슬라이스** | 4개월 | 1장을 출시 품질로. 세 형태의 기본기, 보스 1 | 외부 테스터가 설명 없이 1장을 끝내고 다시 하고 싶어 한다 |
| **3. 데모** | 2개월 | 프롤로그 + 1장, 스토어 페이지 | 넥스트 페스트 참가 |
| **4. 콘텐츠 완성** | 8~10개월 | 5장 전체, 트리 전체, 모든 보스 | 캠페인을 처음부터 끝까지 플레이 가능 |
| **5. 다듬기** | 3~4개월 | 밸런스, 현지화, Steam Deck, 업적 | 형태당 원형 12개 이상이 표준 난이도를 클리어한다 |

### 18.3 프로토타입이 답해야 할 질문

1. 탑다운 카메라에서 절벽을 오르는 적의 **높이가 읽히는가**?
2. 지하에 있을 때 지상의 위기가 **느껴지는가**?
3. 직접 싸우는 방어가 채굴만큼 **재미있는가**? (한쪽이 숙제가 되지 않는가)
4. 귀환 시간이 **긴장인가, 짜증인가**?
5. 추락 규칙이 **노릴 만한가**?
